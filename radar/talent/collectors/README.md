# 채용·인사 수집기 (§12, 인재·조직 레이더 v0)

## 현재 상태
| 수집 대상 | 상태 | 이유 |
|---|---|---|
| 인사 보도자료 | **가동** — T0 뉴스룸 RSS(src-newsroom-*)에 포함, 'event: 인사' 키워드로 radar-triage가 분류 | §12.8 "§10 레이더와 통합" |
| DART 임원 현황·대표이사 변경 | **가동 준비** — DART 키 입력 시 src-dart가 수집. 대표이사변경은 규칙 P0 | |
| 그룹 공식 채용 포털(삼성·SK) | **보류** | 공고 목록이 스크립트 렌더링(JS) 페이지일 가능성이 높고, 약관·robots.txt 확인 전 자동 수집 금지(§21.6). 마스터 확인 후 공개 API 또는 허용된 페이지 구조로 구현 |
| 해외 법인 채용 페이지 | 5단계 | Greenhouse·Lever 등 공개 잡보드 API를 쓰는 곳부터 |
| 미국 노동부 공개 데이터 | 5단계 | 분기 공개 파일 |

## 구현 원칙
- 결정론적 스크립트만(모델 호출 없음). 결과는 `radar/talent/postings/YYYY/MM/DD.jsonl`(§12.3 형식).
- 개인 정보(채용 담당자 이름·연락처)는 저장하지 않는다.
- 수집 전 `robots.txt`를 확인하고 Disallow 경로는 건너뛴다.
