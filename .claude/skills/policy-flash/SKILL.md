# policy-flash — 정책 플래시 (§7.2.3)
```
[모드: flash / 범위: <정책 사건> / 기준시각: … KST] — 1차 판정, 미검증
■ 무엇이 바뀌었나 (원문 기준 2문장)
■ 단계 (예: 규칙안 → 의견 마감 ○○, 최종 규칙 미정)
■ 누가 영향받나 (품목·기업)
■ 한국 기업 노출 (기업·경로·규모 기준)
■ 일정 (의견 마감·시행일·청문회)
■ 한국 정부·업계 대응 가능성 (가설)
■ 기사 각도
```
금지: 규칙안을 시행으로, 보조금 발표를 지급으로(금지표). 저장 `outputs/flash/`.
