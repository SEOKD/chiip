# 분야 모듈: 수동소자·부품(MLCC·인덕터·카메라모듈·FC-BGA) (draft: true — 마스터 검토 전)

> 공통 골격(BUILD_PROMPT §7.5) 위의 분야별 결정 변수. 확신이 없는 기술 내용은 "마스터 확인 필요"로 둔다. 포토·트랙·EUV·메모리 공정은 마스터 수정이 우선이다.

## 분해 대상
- 제품군(IT·전장·산업) → 용량·크기 등급 → 고객 기기(스마트폰·서버·자동차)

## 핵심 변수
- 가동률, ASP, 고용량·소형 믹스, AI 서버당 탑재량(근거 있을 때만), 재고 일수

## 최종 검증 지점
- 회사 콜의 가동률·가격 언급, 일본·대만 동종 업체 월매출(거울)

## 흔한 오류
- 서버당 탑재량을 출처 없이 인용
- 카메라모듈 고객 관계를 공개 근거 없이 단정

## 주요 1차 자료처
- 삼성전기·LG이노텍 IR, 무라타·TDK·야게오 실적

## 레이더 키워드
MLCC, 고용량 MLCC, 실리콘 커패시터, 카메라모듈 (전체 목록은 `config/keywords.yaml`)
