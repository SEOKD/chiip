# org-flash — 인사·조직 플래시 (BUILD_PROMPT §12.5)

## 사전 준비 (인사 시즌 2주 전)
- `knowledge/org/<company>/reshuffle_<YYYY>.md`에 직전 2~3년 비교 표를 **공식 보도자료 기준**으로 만든다.
- 하마평은 필드 인텔(F3·F4)로만 받고 이 노트에 쓰지 않는다.

## 절차 (발표 직후)
1. 발표문을 `source-ingest`로 등록.
2. 아래 지표를 전년·전전년과 **같은 표**로 비교:
   | 지표 | 올해 | 전년 | 전전년 |
   - 직급별 승진자 수(사장·부사장·상무 등)와 부문별 분포(반도체 vs 세트, 메모리 vs 파운드리 vs 패키징)
   - 기술·엔지니어 출신 비중, 연구소 출신 비중 (보도자료에 공개된 범위만)
   - HBM·첨단 패키징·파운드리 고객 대응 관련 보직의 신설·격상
   - 사업부장·연구소장·해외 법인장 교체
   - 외부 영입(경쟁사·고객사·해외)
   - 신설·통합·폐지 조직명
3. 해석: 회사가 보상하는 사업, 전략 키워드, 실적 책임. **"임원 교체 → 전략 전환 확정" 금지**(금지표) — 조직개편·투자 계획·경영진 발언으로 확인할 것을 적는다.
4. 테제 연결(예: HBM 경쟁력, 파운드리 고객 확보).
5. `knowledge/org/<company>/org_changes.csv`에 변경 행 추가, 공개 직책자는 `knowledge/people/`(양식 `docs/templates/person.md`, 공개 직업 정보만).

## 출력 (flash 모드)
```
[모드: flash / 범위: <기업> <연도> 정기 인사 / 기준시각: …] — 1차 판정, 미검증
■ 무엇이 바뀌었나 (3줄)
■ 비교 표
■ 전략 신호 (가설)
■ 테제 연결
■ 확인할 것 (후속 조직개편·분기보고서 임원 현황)
■ 기사 각도
```
저장: `outputs/flash/YYYYMMDD_<entity>_org-flash.md`

## 금지
사생활·가족·연락처·사진, 일반 직원 개인 정보, 공식 발표 전 하마평의 invest·public 사용.
