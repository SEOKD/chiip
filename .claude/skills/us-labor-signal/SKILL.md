# us-labor-signal — 미국 노동부 데이터 (§12.2 T5, §12.7)
1. 공개 파일(분기)을 받아 고용주명이 T0 미국 법인(lexicon legal_entities)인 행만.
2. **집계만** 저장: 고용주·직함 범주·근무지(도시)·임금 구간·건수. 개인 식별 가능 필드는 버린다.
3. 거점별 공정·설비 직무 건수 추이 → 미국 공장 램프 단계 정황(S2), §13 주·지방 서류와 대조.
4. 원천의 공개 주기·필드 구성은 처음 실행 때 공식 페이지로 확인해 이 파일에 기록.
