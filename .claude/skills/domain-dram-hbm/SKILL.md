# 분야 모듈: DRAM·HBM (draft: true — 마스터 검토 전)

> 공통 골격(BUILD_PROMPT §7.5) 위의 분야별 결정 변수. 확신이 없는 기술 내용은 "마스터 확인 필요"로 둔다. 포토·트랙·EUV·메모리 공정은 마스터 수정이 우선이다.

## 분해 대상
- 셀·공정 세대(1a/1b/1c 등) → 다이 → (HBM) 코어다이 적층 + 베이스다이 → 패키지(인터포저 위 GPU·ASIC와 결합)
- 범용 DRAM(서버·모바일·PC) vs HBM vs 기타(GDDR·LPDDR·SOCAMM)

## 핵심 변수
- 비트그로스(공급·수요), ASP, 제품 믹스(HBM 비중)
- HBM: 세대·적층 단수·스택당 용량, TSV·본딩 수율, 베이스다이 공정(자체 vs 파운드리), 고객 인증 일정
- 웨이퍼 투입(kwpm) vs 비트 출하, HBM이 범용 대비 웨이퍼를 더 쓰는 정도(트레이드 레이쇼 — 수치는 근거 있을 때만)

## 최종 검증 지점
- 고객 인증 완료·양산 출하의 회사 공식 확인, 분기 HBM 매출 비중 언급
- 가격: 고정거래가·계약 조건(LTA) 공개 범위

## 흔한 오류
- HBM 베이스다이·코어다이 생산 주체를 세대 구분 없이 단정
- 샘플 출하를 양산으로, 퀄 통과 보도를 공급 확정으로
- 탑재량 기준(다이·스택·GPU·서버) 혼동, Gb/GB 혼동
- 4F²·6F² 셀 논리 단순화(마스터 확인 필요)
- 세대별 인터페이스 폭 혼동: JEDEC HBM4는 스택당 2048비트(HBM3E 1024비트의 2배) — 대역폭 비교 시 핀 속도만 보지 말 것
- 베이스다이 공급 주체를 회사 구분 없이 일반화: SK하이닉스는 TSMC와 HBM4 베이스다이 협력을 공식 발표(2024-04), 삼성은 자체 파운드리 로직 공정 사용이 보도됨 — 세대·회사별로 근거 id를 따로 붙일 것

## 치입 1차 검토 (2026-10-28) — 마스터 확인 필요
- 1c 이후 세대 명칭·EUV 레이어 수, 하이브리드 본딩 도입 세대(HBM4E vs HBM5)는 회사별 공식 발표로만 판단

## 주요 1차 자료처
- 회사 실적 발표·콜, DART 공시(마스터 직접 확인 — 자동 수집 제외), SK하이닉스 SEC 6-K, ISSCC·IEDM·VLSI 메모리 세션, JEDEC 표준 발표
- 후공정 장비: 한미반도체·한화세미텍(TC 본더), BESI(하이브리드 본더) 수주 공시 — 적층 캐파의 거울

## 레이더 키워드
HBM4, HBM4E, 하이브리드 본딩, TC 본더, MR-MUF, 1c DRAM, SOCAMM, CXL (전체 목록은 `config/keywords.yaml`)
