# public-content — 공개 콘텐츠 (§7.4, §21.9, P15)

## 절대 규칙
- 근거는 `public_corroborated: true` 주장과 F1만. local-only·F2~F4·엠바고·`insider_like` 금지(훅 public-guard).
- 투자 권유 금지. 커뮤니티 루머·완곡어 해석·삼각측량 결과를 사실로 쓰지 않는다.
- **자동 게시 금지.** 초안을 `outputs/public/`에 저장하고 마스터에게 보여 준다.
  - **Notion**: 마스터가 "게시 승인"이라고 답한 뒤에만 Notion 커넥터로 페이지 생성·공개. 인사이트 게시글만 — 브리프·플래시는 올리지 않는다.
  - 텔레그램 채널·X·서브스택·유튜브: 초안만. 게시는 마스터가 직접.
- 언어: 글로벌 공개 콘텐츠는 영어, 국내는 한국어.

## 형식
| 채널 | 형식 |
|---|---|
| Notion 인사이트 | 제목 / 한 줄 결론 / 왜 지금 / 근거(공개 출처 링크) / 반대 시나리오 / 다음 확인 / 면책 문구 |
| 텔레그램 짧은 글 | 5줄 이내 + 출처 링크 |
| X 스레드 | 5~8개 트윗, 첫 트윗에 결론 |
| 서브스택 장문 | report 모드 구조 |
| 유튜브 대본 | 3분 분량, 도입 15초 결론 |

## 절차
1. 대상 주장·카드 선정 → 공개 가능 여부 점검표(위 규칙) 통과.
2. 초안 작성 → `outputs/public/YYYYMMDD_<channel>_<slug>.md` (훅이 검사).
3. editor 에이전트로 다듬기 → 마스터에게 제시 → 승인 시에만 게시(Notion) 또는 마스터가 직접 게시.
