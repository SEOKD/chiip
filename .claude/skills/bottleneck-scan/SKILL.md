# bottleneck-scan — 병목 진단 (§7.3)

## 5분류
| 분류 | 질문 |
|---|---|
| 물리 | 물리 법칙·재료 한계(열·전력 밀도·신호 손실·리소그래피 해상도) |
| 제조 | 수율·장비·공정 창·캐파·리드타임 |
| 상업화 | 표준·고객 인증·생태계·소프트웨어 |
| 실행 | 기업 역량·인력·자금·일정 |
| 경제성 | 비용 곡선·가격·TCO·투자 회수 |

## 절차
1. 최종 수요(워크로드·시스템)에서 출발해 시스템 구조상 병목 후보를 나열.
2. 각 후보를 5분류에 배치, 근거(주장 id)와 확신도.
3. 해결 기술·기업(대안 포함)과 각자의 대가(trade-off).
4. **해소 후 다음 병목**: 이 병목이 풀리면 어디로 제약이 이동하나.
5. 부가가치 이동: 누가 유리해지나(가설 표시).

## 출력
report 모드 구조 + 병목 지도 표. 저장 `outputs/report/YYYYMMDD_bottleneck_<topic>.md`.
