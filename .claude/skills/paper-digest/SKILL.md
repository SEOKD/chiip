# paper-digest — 논문 정리 (§7.3, §10.8)

## 절차
1. `source-ingest` 등록(doc_type 논문·학회발표). 공개 범위 밖 원문은 저장하지 않는다.
2. 정리 틀:
   | 항목 | 내용 | 위치(쪽·그림) |
   |---|---|---|
   | 요구조건 | 어떤 시스템 요구(대역폭·전력·밀도·지연)를 겨냥하나 | |
   | 현재 제약 | 기존 방식의 한계 | |
   | 작동 원리 | 핵심 아이디어 | |
   | 대가 | 면적·전력·공정 복잡도·비용 | |
   | 대안 | 경쟁 접근 | |
   | 적용 결과 | 측정값(조건·단위 명시, 시뮬레이션인지 실측인지) | |
   | **양산까지 남은 병목** | 장비·재료·수율·표준·고객 인증 | |
3. 저자 소속 기업 → 상용화 세 축 중 어디까지 시사하나(학회 발표는 보통 '개발'). 샘플·양산으로 확대 해석 금지.
4. 주장 승격: claim_type 확정사실(측정값) 또는 자체추론(해석).

## 저장
`outputs/report/YYYYMMDD_paper_<cf>_<short>.md`.
