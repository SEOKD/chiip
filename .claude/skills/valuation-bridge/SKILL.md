# valuation-bridge — 밸류에이션 브리지 (§7.4)
**invest 모드 경계**: `D:\local-only`와 F2~F4 필드 인텔 사용 금지, `public_corroborated: true` 주장과 F1만. 출력 하단에 `공개 자료 기반 분석이며 투자 권유가 아님`. 매수·매도 권유·개인 맞춤 투자 조언 금지(훅 public-guard가 강제).

## 다리
`시스템 출하(단위 명시) × 적용률 × 탑재량 = 부품 수요` → `× 점유율 × ASP = 매출` → `× 마진 = 이익` → `− CAPEX·운전자본 = 현금흐름`
1. 각 변수에 근거(주장 id)·기준(단위·기간)·확신도.
2. 시나리오 표(강세·기본·약세): 변수별 값과 그 값을 정당화하는 사건(반증 조건과 연결).
3. 민감도: 가장 영향 큰 변수 3개의 ±10%·±20% 영향.
4. 가치 환산은 멀티플 범위(동종 비교, 출처) 또는 단순 DCF — 하나의 목표가로 수렴시키지 않고 범위로.
5. 위험보상 비대칭(하방 대비 상방) 서술.
