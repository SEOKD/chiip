# reframe-check — 재진술 검증 (§7.3, P10)

## 절차
1. 문장을 주장 단위로 쪼갠다.
2. 각 주장에 대해 근거(주장 id·원천)를 찾는다.
3. 판정 표:
   | 부분 | 판정(맞음·조건부·틀림·미확인) | 근거 | 누락 조건 |
4. 금지표 위반(잘못된 연결) 표시.
5. **수정 문장** 1~2개 제시 — 근거가 지지하는 범위까지만.

마스터의 가설이라도 같은 강도로 검증한다. 동의하기 위해 기준을 낮추지 않는다.
