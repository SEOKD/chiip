# yama-check — 야마 점검 (§7.3)

## 점수 (각 0~3, 근거 1줄)
| 항목 | 질문 |
|---|---|
| 신규성 | 이미 보도된 내용인가(국내·해외), 새 숫자·새 사실이 있나 |
| 경제적 의미 | 실적·투자·고용·산업 구조에 미치는 크기 |
| 한국 기업 연결 | T0·T1 기업의 실적 동인과 직접 연결되나 |
| 시의성 | 지금 써야 할 이유(일정·경쟁 보도·엠바고 해제) |

## 출력 (article 모드)
- **야마 1문장**
- 근거 사실(주장 id·1차 출처), 아직 미확인인 부분
- 보강 취재 질문 3~5개(누구에게 무엇을 확인할지 — 취재원 이름은 쓰지 않음)
- 반론·리스크(금지표 위반 소지)

## 금지
근거 없는 단정, 취재원 노출, 엠바고 해제 전 내용.
