# 분야 모듈: 파운드리·로직·IP (draft: true — 마스터 검토 전)

> 공통 골격(BUILD_PROMPT §7.5) 위의 분야별 결정 변수. 확신이 없는 기술 내용은 "마스터 확인 필요"로 둔다. 포토·트랙·EUV·메모리 공정은 마스터 수정이 우선이다.

## 분해 대상
- 공정 노드(GAA·후면전력) → PDK·IP 생태계 → 고객 테이프아웃 → 양산 → 패키징(턴키)

## 핵심 변수
- 수율·D0, 웨이퍼 가격, 가동률, 고객 수·테이프아웃 수, IP 포트폴리오

## 최종 검증 지점
- 고객의 공식 발표·공시(디자인윈·양산 제품 출시), 실제 칩 분해 분석
- 회사 콜의 매출 비중·가동률

## 흔한 오류
- '첨단 노드' 임의 특정(출처 없으면 미확인)
- 디자인윈 = 양산 매출 단정, 테스트칩 = 고객 확보 단정
- 공정 이름 마케팅 수치를 물리 치수로 해석

## 주요 1차 자료처
- TSMC·삼성 파운드리 포럼, VLSI·IEDM 로직 세션, 고객사 제품 발표

## 레이더 키워드
2nm, SF2, GAA, 후면전력, PDK, 턴키 (전체 목록은 `config/keywords.yaml`)
