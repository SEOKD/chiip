# 분야 모듈: 장비·소재 (draft: true — 마스터 검토 전)

> 공통 골격(BUILD_PROMPT §7.5) 위의 분야별 결정 변수. 확신이 없는 기술 내용은 "마스터 확인 필요"로 둔다. 포토·트랙·EUV·메모리 공정은 마스터 수정이 우선이다.

## 분해 대상
- 공정 단계별 장비(노광·트랙·증착·식각·CMP·계측·후공정) → 고객 팹 CAPEX → 장비사 수주·매출 → 소재 소모량

## 핵심 변수
- 고객 CAPEX 가이던스, 장비사 지역별(한국) 매출, 수주잔고, 리드타임
- 공정 전환에 따른 장비 강도(단계 수 증가)

## 최종 검증 지점
- 장비사 지역별 매출·수주 공시, 일본·네덜란드 대한국 장비 수출 통계(거울)
- 고객 팹 장비 반입 보도·인허가

## 흔한 오류
- 고객 투자 발표 → 특정 장비사 매출(공급 관계·점유율 필요)
- 수주와 매출 인식 시점 혼동

## 주요 1차 자료처
- 장비사 실적 콜(ASML·AMAT·LRCX·KLA·TEL), SEMI·SEAJ 통계, SPIE Advanced Lithography

## 레이더 키워드
EUV, High-NA EUV, ALD, 식각, 장비 반입 (전체 목록은 `config/keywords.yaml`)
