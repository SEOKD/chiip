# 분야 모듈: 기기·로보틱스 (draft: true — 마스터 검토 전)

> 공통 골격(BUILD_PROMPT §7.5) 위의 분야별 결정 변수. 확신이 없는 기술 내용은 "마스터 확인 필요"로 둔다. 포토·트랙·EUV·메모리 공정은 마스터 수정이 우선이다.

## 분해 대상
- 완제품(스마트폰·XR·폴더블·휴머노이드) → 핵심 부품(카메라·센서·디스플레이·구동부) → 공급사

## 핵심 변수
- 출하량, 부품 탑재량·사양 변화, 출시 일정

## 최종 검증 지점
- 제조사 공식 발표·분해 분석, 공급사 실적 언급

## 흔한 오류
- 출시 루머 = 확정, 프로토타입 = 양산

## 주요 1차 자료처
- 제조사 발표, CES, 분해 분석(공개 범위)

## 레이더 키워드
휴머노이드, XR, 폴더블 (전체 목록은 `config/keywords.yaml`)
