# consensus-gap — 컨센서스 갭 (§7.4, 금지표 '시장이 간과했다')
**invest 모드 경계**: `D:\local-only`와 F2~F4 필드 인텔 사용 금지, `public_corroborated: true` 주장과 F1만. 출력 하단에 `공개 자료 기반 분석이며 투자 권유가 아님`. 매수·매도 권유·개인 맞춤 투자 조언 금지(훅 public-guard가 강제).

1. 컨센서스 확인: 공개 범위 컨센서스(출처·기준일), `ib-digest` 추정치 변경 기록. 못 구하면 "컨센서스 미확인" → 갭 결론 금지.
2. 가격 내포 기대: 현재 멀티플이 요구하는 성장·마진 역산(가정 명시).
3. 치입 판단(모델·테제)과 비교 표: | 변수 | 컨센서스 | 가격 내포 | 치입 | 차이 근거 |
4. **variant perception** 3줄: 무엇을, 왜 다르게 보며, 언제 확인되나(카탈리스트).
5. "이미 반영됐을 가능성"을 red-team과 함께 검토.
