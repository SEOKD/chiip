# 분야 모듈: 패키징·기판·PCB·소재 (draft: true — 마스터 검토 전)

> 공통 골격(BUILD_PROMPT §7.5) 위의 분야별 결정 변수. 확신이 없는 기술 내용은 "마스터 확인 필요"로 둔다. 포토·트랙·EUV·메모리 공정은 마스터 수정이 우선이다.

## 분해 대상
- 첨단 패키지(CoWoS류·SoIC류·패널레벨·유리코어) → 패키지 기판(FC-BGA, ABF) → 메인보드·가속기 보드(고다층 MLB) → 소재(CCL·동박·유리섬유)

## 핵심 변수
- 기판: 층수·면적·수율·리드타임·가동률, AI 서버 비중
- MLB: 층수·두께·소재 등급, 고객(가속기·스위치) 비중
- CCL·동박·유리섬유: 저유전 등급 믹스(M8/M9 등), HVLP 동박 비중, 공급 부족 여부

## 최종 검증 지점
- 고객·공급사 공시·월매출(대만·일본 거울), 회사 증설 공시·가동 발표
- 고객 제품 분해·사양서의 소재 등급(공개 범위)

## 흔한 오류
- 기판 증설 발표 = 공급 증가(수율·고객 인증 필요)
- 유리기판 시제품 = 양산 단정
- 부품 성능 개선 → 시스템 성능 개선 직결
- 대만 월매출 거울 해석 시 환율(TWD)·연결 범위 변경 무시 — 단위는 천 TWD(t187ap05_L 기준)
- CoWoS 캐파(웨이퍼/월)를 GPU 출하 대수로 단순 환산(다이 크기·HBM 스택 수·수율에 따라 다름)

## 주요 1차 자료처
- 회사 IR·공시, ECTC·IMAPS, 대만 월매출(MOPS), 소재 업체 실적

## 레이더 키워드
CoWoS, SoIC, PLP, 유리기판, FC-BGA, ABF, MLB, CCL, HVLP, 저유전 유리섬유 (전체 목록은 `config/keywords.yaml`)
