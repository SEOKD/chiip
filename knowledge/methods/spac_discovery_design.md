# SPAC 발굴 파이프라인 설계안 (초안 — 마스터 승인 전)

> 마스터 지시(2026-11-04): "Pulse와 Ten-bagger 기능에 SPAC 종목도 발굴하는 파이프라인과 시스템을 설계하라."

**지금 있는 것:**
- SPAC 리포트 경로 `scripts/tenbagger/spac_report.py`(2026-11-03): 이미 고른 스팩을 합병 위임장 중심으로 분석한다.
- Pulse '신규 상장'(424B4·S-1): 업종 SIC가 AI·반도체·전력일 때만 본다.

**빠진 것: 스팩을 찾는 단계.** 스팩의 SIC는 6770(백지수표 회사)이라 지금 업종 관문에 걸리지 않는다. 피인수 기업의 업종은 서류 본문에만 있다. CCXI(Agility Robotics)도 마스터가 알려 줘서 들어왔다.

**경계:**
- 연구 후보이지 매수 권유가 아니다. 매매·비중 지시는 쓰지 않는다.
- 1차 자료는 SEC EDGAR가 중심이다. 유료 스팩 추적 서비스(SPACInsider·SPAC Research 등)는 쓰지 않는다(유료벽).
- 경영진 전망은 '경영진 전망'으로만 쓰고, 컨센서스로 부르지 않는다.

## 1. 스팩 생애 단계와 1차 서류 (상태 기계)

| 단계 | 사건 | EDGAR 서류(제출자 SIC 6770) | 치입이 볼 숫자 |
|---|---|---|---|
| S0 상장 | 백지수표 IPO | S-1, 424B4 | 신탁 규모·주당 신탁가, 스폰서, 목표 업종 문구, 시한 |
| S1 단서 | 협상 보도·LOI | (서류 없음) 언론 제목, 8-K 7.01 | 주요 매체 단독·관계자 보도만 |
| S2 확정 계약 | 합병 계약 체결 | 8-K 1.01 + EX-99.1 보도자료·EX-99.2 투자설명 자료, 425 | 피인수 기업·업종, 합병 가치(EV), PIPE·전환사채, 최소 현금 조건 |
| S3 등록 | 합병 등록 서류 | S-4/F-4와 정정본, EFFECT(효력 발생) | 경영진 전망, 공정성 의견 범위, 희석 표 |
| S4 주총 | 투표·환매 | DEFM14A·424B3, 연장 DEF 14A, 8-K 5.07 | 환매율, 남은 신탁, 시한 연장·신탁 인출 |
| S5 종결 | 합병 완료 | 8-K 2.01·슈퍼 8-K, 티커 변경 | 최종 주식 수, 순현금, 언아웃, 보호예수 |
| S6 합병 후 | 일반 상장사 | 10-Q·10-K, S-1 재매각 등록, 워런트 상환 공지 | 보호예수 해제·재매각 물량(오버행), 첫 실적 |

장부: `knowledge/models/spac/registry.csv`. 칸은 스팩 CIK·티커, 피인수 기업, 단계, 단계 진입일, 신탁가, 시한, 테마, 출처 URL이다. 단계 전환이 곧 Pulse 사건이다.

## 2. Pulse — 결정론 감지 관문 (모델은 관문을 넘은 건만 판단)

1. **EDGAR 최신 목록**(2026-11-04에 만든 `radar/pollers/edgar_current.py`를 넓힌다):
   - 지금은 8-K·6-K만 2분마다 본다. 여기에 425·S-4·F-4·DEFM14A를 더한다.
   - 제출자 SIC 6770, 또는 장부에 있는 스팩 CIK만 통과시킨다.
2. **본문 테마 판정**(결정론):
   - 8-K EX-99.1·425 첫 페이지에서 피인수 기업 사업 문구를 읽어 Chiip 테마 어휘와 대조한다.
   - 어휘는 `radar/pulse.py` TECH_RE와 `config/discovery.yaml` 테마의 이름·별칭이다(AI·반도체·데이터센터·전력·원자력·우주·로봇·양자·광학·방산).
   - 일치하지 않는 스팩은 장부에만 남기고 알리지 않는다.
3. **주가 관문:** 스팩 주가 / 주당 신탁가(프리미엄), 워런트 가격, 거래량. 데이터는 TradingView 배치(한 번에 하나씩) 또는 Fiscal.ai.
4. **알림 유형 '🧩 SPAC'** — 단계 전환일 때만 보낸다.
   - S2 확정: 피인수 기업 1줄 + 합병 가치 + 아래 숫자
   - S3 효력 발생, S4 환매 결과, S5 종결: 같은 숫자를 단계에 맞게
   - 넣는 숫자(상대 지표 원칙): 신탁가 대비 프리미엄 %, 주당 순현금(아래 3-②), 동종 EV/매출 대비 합병 가치
5. **S1 단서:** 기존 '속보 판단' 규칙을 쓴다(주요 매체 단독·관계자 보도 + 감시 기업). 결과는 '정황'으로만 쓴다.

## 3. 정량 — SPAC 비대칭 점수 (10점, `scripts/tenbagger/spac_score.py` 예정)

스팩 수익은 일반 주식과 모양이 다르다. 주총 전에는 신탁가가 바닥(환매권)이고, 종결 뒤에는 희석·오버행이 크다. 그래서 단계별로 다른 식을 쓴다.

| 요인 | 식 | 근거·기저율 | 가중(사전) |
|---|---|---|---|
| ① 바닥(주총 전만) | 신탁 수익률 = (시한의 주당 신탁가 / 주가)^(1/잔여년) − 1. 프리미엄 ≤ 3%면 바닥 인정 | 환매권 = 신탁가 하방 보호. 스팩 차익의 원리(Gahng, Ritter & Zhang 2023, RFS) | 0.15 |
| ② 희석 | 주당 순현금 = (환매 후 신탁 + PIPE − 수수료) / 전체 주식(스폰서·워런트 내재가치 포함) | Klausner, Ohlrogge & Ruan 2022(Yale J. on Reg.) — 주당 $10 중 중앙값 약 $5.7만 남는다 | 0.20 |
| ③ 사업 엣지 | Chiip 테마 렌즈 점수(병목·해결 기술·양산성·고객 채택, 기존 알파의 bottleneck 항목과 같은 틀) | 치입 판단 | 0.25 |
| ④ 가치 | 합병 EV / 선행 매출을 동종 EV/매출과 비교. 경영진 전망은 50% 할인 | 스팩 경영진 전망의 과대 경향(Kiesel 등 2023; Dambra, Even-Tov & George 2021) | 0.20 |
| ⑤ 오버행·구조 | 보호예수 해제 6개월 내 물량 / 유통 주식, 언아웃 조건, 재매각 S-1 | 합병 후 6~12개월 수익 약세 기저율(Gahng, Ritter & Zhang) | 0.10 |
| ⑥ 시장 관심 | 발표 뒤 프리미엄·거래대금·환매율(높은 환매 → 유통 주식 작음 → 변동성) | 쏠림·숏 스퀴즈 위험(양방향) | 0.10 |

- 단계 가중:
  - 주총 전(S2~S4): ①②④를 중심으로 본다.
  - 종결 뒤(S5~S6): ①을 빼고, ③④⑤를 중심으로 본다.
- 기저율 표시: 합병 후 1년 수익의 중앙값은 시장보다 크게 낮다(위 문헌). 그래서 텐배거 확률은 일반 소형주보다 **낮은 기저율에서 출발**한다. 대신 꼬리(소수의 큰 승자)를 따로 센다.
  - Chiip 자체 표본: 2021~2025 합병 종결 스팩의 EDGAR 서류와 시세로 다시 계산한다(4단계).
- **킬 조건:** 계약 해지, 최소 현금 조건 미달, PIPE 철회, 시한 연장만 반복하고 거래가 없음, 환매 95% 이상에 PIPE 없음, 재매각 S-1 대량 등록.

## 4. Ten-bagger 연결

| 기존 단계 | 스팩일 때 |
|---|---|
| 발굴(Discovery) | 장부에서 S2 이상 + 테마 일치 + 비대칭 점수 ≥ 6.0만 후보 |
| 알파 잠재력 | 컨센서스가 없으므로 upside = ④ 가치(전망 할인), gap = 프리미엄과 시장 관심, bottleneck = ③, asymmetry = ①·② |
| 카드·리포트 | 이미 있는 `spac_report.py` 경로(1-S 절차). 목표주가·구매 등급 없음 |
| 추적 | `watch.csv`에 단계 칸을 둔다. 단계가 바뀌면 카드를 갱신한다 |
| Portfolio 와치리스트 | 자동 편입은 S5 종결 뒤, 일반 규칙과 같게(알파·종합 분위). 주총 전 스팩은 연구 명단에만 둔다 |

## 5. 파라미터 (등록부 prm-spac-* 예정, 모두 사전값)
`floor_premium_max 0.03` · `projection_haircut 0.5` · `redemption_prior 0.85`(최근 몇 년 환매율 수준 — 확인 후 갱신) · `net_cash_min 5.0` · 요인 가중 6개 · `score_min 6.0` · 오버행 창 180일.
피팅은 4단계 표본(과거 합병 종결 스팩)으로 표본 외에서만 한다. 과적합을 막기 위해 가중은 단계별 2가지만 둔다.

## 6. 단계 계획

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1 | EDGAR 스팩 감지(SIC 6770 + 425·S-4·DEFM14A·8-K 1.01) + 상태 장부 | 지금 살아 있는 스팩 목록과 단계가 장부에 찬다 |
| 2 | 본문 테마 판정 + Pulse '🧩 SPAC' 알림(단계 전환만) | 테마 일치 S2 이상이 2분 안에 알림 |
| 3 | 비대칭 점수 + Ten-bagger 발굴·알파 연결 | 후보 카드, spac_report 자동 연결 |
| 4 | 과거 표본(2021~2025 종결 스팩)으로 기저율·가중 점검 | 단계별 이후 수익 분포, 텐배거 비율 |
