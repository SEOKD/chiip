# 원자력·위성 밸류체인 분석 틀

> 마스터 지시(2026-10-31): "CCJ, LEU, Babcock 같은 원자력 밸류체인 종목과 YSS, RKLB, PL 같은 위성 밸류체인 종목도 종목발굴 레이더 망에 포함시켜줘."
> 지도: `config/discovery.yaml` 테마 `nuclear_fuel`·`nuclear_reactor`·`satellite_launch`·`satellite_data`(`watch: true` — 레이더 종목 인식·SEC 공시·수집 관문에 자동 연결). 구간 엔진 섹터 `nuclear`·`space`.

두 분야 모두 발표에서 매출까지가 길고, 정부 인허가·계약 단계가 실적을 가른다. 단계를 나눠 적고 한 단계로 다음 단계를 채우지 않는다.

## 원자력
- **보는 사슬:** 우라늄 채굴 → 변환 → 농축 → 연료 가공 → 원자로 주기기·해군 추진 → 건설·운영 서비스.
- **가격 동인:** 현물가보다 장기 계약 가격과 계약 물량을 본다. 생산사의 실현 단가는 계약 구조로 현물보다 늦게 움직인다.
- **병목:** 변환·농축 캐파(러시아산 대체), 고순도 저농축 우라늄(HALEU) 공급, 압력용기 대형 단조, 인허가 인력.
- **단계 표기:** 사전 신청 → 설계 승인 → 건설 허가 → 운영 허가 → 착공 → 연료 장전 → 상업 운전.

| 잘못된 연결 | 필요한 검증 |
|---|---|
| 현물 우라늄 상승 → 생산사 이익 증가 | 장기 계약 비중·가격 하한·상한·실현 단가 |
| SMR 양해각서·예비 협약 → 수주 | 구속력 있는 계약·최종 투자 결정·자금 조달 |
| 설계 승인 → 건설 확정 | 건설 허가·부지·전력 구매 계약·EPC 계약 |
| 정부 프로그램 선정 → 자금 수령 | 최종 계약·지급 실적·조건 이행 |
| 데이터센터 원전 전력 계약 → SMR 매출 | 상업 운전 시점·기존 원전 계약 여부 구분 |
| 농축 증설 발표 → 공급 증가 | 인허가·원심분리기 설치·가동·판매 계약 |

## 위성
- **보는 사슬:** 발사체 → 위성 버스·탑재체 → 지상국·운영 → 데이터·통신 서비스.
- **가격 동인:** 발사 횟수 × 건당 가격, 위성 기수 × 단가, 데이터 구독 × 재계약률. 수주잔고(backlog)는 정부 옵션 포함 여부를 나눠 본다.
- **병목:** 발사 슬롯, 위성 버스 양산, 방사선 내성 부품, 주파수 사용권.
- **단계 표기:** 개발 → 시험 비행 → 첫 궤도 성공 → 반복 발사 / 시제 위성 → 양산 위성군 → 서비스 개시 → 구독 재계약.

| 잘못된 연결 | 필요한 검증 |
|---|---|
| 신형 발사체 발표 → 발사 매출 | 궤도 성공·발사 주기·고객 계약 |
| 수주잔고 증가 → 매출 확정 | 확정 금액 vs 옵션·발주액(obligated)·인도 일정 |
| 정부 위성군 선정 → 공급사 이익 | 트랜치별 계약 금액·고정가 여부·원가 |
| 위성 발사 성공 → 데이터 매출 | 가동 위성 수·구독 계약·재계약률 |
| 주파수·파트너 계약 → 서비스 매출 | 규제 승인·위성군 규모·유료 가입자 |
| 시험 성공 → 양산 성공 | 양산 수율·공급사 납기·반복 생산 |

방위와 겹치는 종목(Babcock·BWXT·Rocket Lab 등)은 `knowledge/methods/defense_lens.md`의 예산 단계도 같이 본다.
