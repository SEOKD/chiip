# AAP-20261031-02 — CLAUDE.md 출력 채널 절을 기능별 지시서로 옮긴다

상태: 제안, 마스터 승인 대기 (CLAUDE.md는 고도화 대상 바깥)

- 변경: CLAUDE.md '출력 채널' 절(줄마다 수백 자, 최장 1,274자)의 기능별 세부를 이미 있는 `docs/tasks/*`·`knowledge/methods/*`로 옮기고, CLAUDE.md에는 매번 필요한 사실과 경계만 남긴다. 내용은 지우지 않고 위치만 옮긴다.
- 이유: 공식 문서는 긴 파일이 준수를 떨어뜨린다고 적고, 여러 단계 절차는 스킬·경로별 규칙으로 옮기라고 권한다. 지금은 펄스 회차가 텐배거 양식까지 매번 읽는다.
- 예측: 펄스 회차 지시문 57,237자가 45,000자 이하. `rule_evals.py --gate` 악화 없음. 2주 판정.
- 깨질 위험: 기능 경계에 걸친 지시를 놓칠 수 있다. 마스터 지시 원문의 추적이 어려워진다. 완화: 옮긴 뒤 CLAUDE.md에 위치 색인 한 줄씩 남기고, 예약 작업 지시문이 해당 파일을 읽는지 전수 확인한다.
- 측정 한계: 준수율 향상은 아직 증거가 아니다. 지금 강제 안 된 규칙의 위반이 분량 때문인지는 이 측정으로 가를 수 없다. 옮긴 뒤 전후 비교가 검증이다.
