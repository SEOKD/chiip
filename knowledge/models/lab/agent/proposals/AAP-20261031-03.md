# AAP-20261031-03 — Proviser 보강 지시에 근거와 만료를 붙인다

상태: 제안, 일요일 Proviser 검토 대상

- 측정: `docs/proviser/` 활성 지시 47건, 합계 69,644바이트. 근거 줄 없는 지시 4건(model-lab D-20261029-01, portfolio X-20261029-02·03, tenbagger D-20261029-01).
- 변경: 지시마다 근거(실제 산출물 표본)를 필수로 하고, 14일간 해당 위반이 다시 측정되지 않으면 졸업 또는 삭제 후보로 올린다.
- 이유: 보강 지시는 사실상 에이전트의 반성 메모리다. 메모리 서베이는 틀린 교훈이 근거 확인 없이 굳는 위험과 만료 장치의 필요를 짚는다.
- 예측: 활성 지시 47건이 2주 뒤 35건 이하, `rule_evals.py --gate` 악화 없음.
- 깨질 위험: 드물게 쓰는 지시가 만료로 사라질 수 있다. 마스터 지시에서 나온 상시 원칙은 만료 대상에서 뺀다.
