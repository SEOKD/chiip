# Chiip Analysis(텐배거 일일 리포트) 밸류에이션 기법 점검 — 2026-10-29

> 마스터 지시: "텐배거 종목 중 하나를 꼽아 매일 리포트를 제공하는 Chiip Analysis에 맥킨지 밸류에이션이나 월스트리트 IB 리서치 하우스가 사용하는 최신 기법이 모두 반영됐는지 다시 점검하라." 그리고 "밸류에이션 모델링을 할 때 easyconomics에서 컨센서스와 어닝콜 스크립트 등 기업 정보를 모두 취합해 이를 변수로 활용하도록 아키텍처를 설계하라."

## 결론
- 엔진(밸류에이션 v2, `scripts/valuation/v2/`)은 맥킨지 『Valuation』 골격을 대부분 갖고 있었다. 그러나 **일일 리포트가 엔진을 쓰지 않았고**, 동인(성장·이익률·재투자)을 손으로 넣어 컨센서스·어닝콜이 변수로 들어가는 길이 없었다.
- 오늘 고친 것: ① 데이터 묶음(datapack) → 동인 자동 생성(`build_drivers.py`) ② v2 결과 → 리포트 '밸류에이션' 절 자동 생성(`v2_to_report.py`) ③ 상대가치 회귀·민감도 격자·몬테카를로 분포 차트 ④ 예약 작업 지시서에 의무 단계로.

## 남은 한계 (다음 개선 후보 — model-lab 제안서로)
- **부문별 합산(SOTP):** 사업부가 여러 개인 기업(INNIO 장비·서비스 등)은 부문 분리 동인이 필요. 지금은 단일 동인.
- **실패 확률 보정(Damodaran):** 적자·초기 기업은 '계속기업 가치 × (1−실패확률) + 청산가치 × 실패확률'이 필요. 지금은 약세 시나리오로만 대신.
- **추정치 수정 모멘텀:** 컨센서스 90일 변화(datapack revisions_90d)를 아직 동인·확률에 쓰지 않는다.
- **단위 경제·TCO(SemiAnalysis식):** 칩·시스템 기업은 고객 TCO 비교가 핵심인데 정성으로만 쓴다.
- **동종사 표본:** easyconomics company_peers로 4사 이상을 모으도록 지시했지만, 동종 이익률·성장 데이터 품질은 회차마다 확인 필요.
- 초고성장(1년차 +100% 이상) 기업은 동인 규칙(빠른 감속·변동성 상한)이 결과를 크게 좌우한다 — 모델이 overrides와 이유를 반드시 적는다.

## 첫 적용 — CBRS
- 컨센서스(FY26 8.9억 → FY27 29.1억 달러)를 동인으로, 이익률·재투자는 이유를 적은 수동 보정.
- 결과: WACC 11.5%, 기본 0.23배(가장 관대한 가정 0.5배), 시장 내포 5년 매출 CAGR 178%. 판단 시나리오(배수 기준 1.1배)와의 차이를 리포트에 명시 — **자본 집약도(웨이퍼 수명)가 두 방법의 차이를 만든다.**

## 2차 점검 — CBRS 전 과정(원자료 → 동인 → 계산 → 리포트), 2026-10-29 저녁
> 마스터 지시: "시나리오별 내재가치 base 0.23배·5년 뒤 0.38배가 어떤 멀티플인가, 수치가 이상하다" → "밸류에이션 과정과 easyconomics 로우 데이터가 변함 없는지 전 과정을 10점 만점으로 점검하고 10점으로 고도화하라."

| 단계 | 발견 | 조치 |
|---|---|---|
| 표기 | '0.23배'는 멀티플이 아니라 DCF 주주가치 ÷ 현재 시가총액, '5년 뒤'는 할인 전 미래 가치 ÷ 현재 시총인데 표에 정의가 없었다. '계속가치 비중 594%'는 의미 전달 실패 | 표 제목·읽는 법·기업가치 분해(1~10년 PV vs 계속가치) |
| 원자료 | 가이던스 누락(FY26 코어 매출 8.8~8.9억$·코어 영업이익률 −18%) · 어닝콜 톤 flat(레이더는 가이던스 상향·톤 +1.1) · TTM 영업이익 1H 연환산(−0.9 vs 실제 −0.552) · 투하자본 PBR 역산(3.15 vs 재무상태표 2.72) · 희석 주식 출처 없음(0.055 vs SEC 0.076) · 동종사 2곳·TTM 값을 '선행'으로 표기 · 매출(코어)과 이익률(비GAAP) 기준 미표기 | 데이터 묶음 재작성 + 원자료 스냅숏(raw) + `datapack_check.py` 13개 대조(옛 묶음 5.0 → 새 묶음 10.0) |
| 동인 | 목표 이익률 덮어쓰기가 1년차(FY27) 이익률을 컨센서스 +3% 대신 −36%로 만듦 · 덮어쓰기가 동인 전체를 대체 · 비GAAP 이익률을 GAAP처럼 사용 | 컨센서스 연도 앵커 고정, 덮어쓰기는 준 항목만 병합, 비GAAP → SBC 차감 |
| 계산 | '5년 뒤' 가치가 적자를 이자 없는 차입으로 메워 부풀음(2배 필요 성장 < 시장 내포 성장의 역전) | 순현금엔 세후 이자, 부족분엔 WACC |
| 해석 | 민감도가 WACC×영구성장(계속가치 RONIC=WACC라 성장률은 가치에 거의 무영향) | 장기 이익률 × 매출÷투하자본 격자 + WACC·RONIC 한 줄, 동종 회귀는 같은 기준(TTM)끼리 |

결과(CBRS): 기본 0.23 → 0.28배, 강세 0.65배, 약세 0.20배(확률 0.2·0.5·0.3), MC P50 0.29배, 시장 내포 5년 매출 CAGR 164% vs 컨센서스 경로 70%, 동종 회귀 내포 EV/매출(TTM) 19배 vs 현재 41배. 점수: 4.5 → 10/10(데이터 검증 10.0, 회귀 시험 5개 추가). 남은 판단 가정(목표 이익률 22%·매출÷투하자본 1.0·SBC 6%)은 동인 출처 표에 이유와 함께 공개.
