# 딘스티커 읽기 운영 규칙

> 마스터 지시 2026-10-31 "내가 딘스티커 채널에 올리는 인사이트를 너가 참고하도록 … 에이전트가 딘스티커 채널에 피드를 보내는 건 금지한다. 오로지 읽기 기능만".

- **읽기만 한다.** `radar/dticker.py`가 공개 웹 미리보기 `t.me/s/d_ticker`를 30분마다 GET으로 읽는다. 채널 쓰기 기능을 만들지 않는다.
- **채널 발송 금지.** `notify.private_chat`이 개인 대화방이 아닌 곳(채널·그룹·@핸들)으로 가는 발송을 전부 거부한다. 봇을 채널 관리자로 넣더라도 막힌다.
- **쓰는 법:** `py radar/dticker.py --about <종목명·티커>`(그 종목에 대해 마스터가 쓴 글), `py radar/dticker.py --recent 14 --columns`(최근 칼럼).
- **참고할 때:**
  - 마스터의 공개 견해로 다룬다. 사실이 아니라 가설이고, 같은 강도로 반대 검증한다.
  - '※ 에이전트 결과물입니다'가 붙은 글은 치입 글이므로 마스터 의견으로 쓰지 않는다. 표시 없는 글도 치입 산출물과 내용이 같으면 독립 확인으로 세지 않는다.
  - 주장(claim)의 출처로 쓰지 않는다. 글이 인용한 1차 자료를 직접 연다.
  - 치입 판단이 글과 다르면 숨기지 말고 차이와 근거를 쓴다. 맞추려고 판단을 바꾸지 않는다.
  - 인용할 때는 글 링크를 붙이고, 15단어 이하로 줄인다.
  - 이미 채널에 올린 내용을 그대로 되풀이해 보내지 않는다. 치입이 더한 것만 쓴다.
- **쓰는 곳:** 펄스 판단 건, 실적 ③ 칼럼, 텐배거 리포트 내러티브, 기사 소재, 인사이트 검토, Weekly Review.
- **등급:** 공개 글이라 F1, invest·public에서 쓸 수 있다. 마스터의 보유 포지션을 추정하는 데 쓰지 않는다.
- **새 글이 와도 알림을 보내지 않는다.** 마스터가 직접 쓴 글이다.
