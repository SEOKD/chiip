- **밸류에이션 주간 갱신**(2026-10-31 마스터 지시): 모델은 최신 논문·기술 자료·IB 리서치 하우스 공개 자료를 참조해 매주 갱신한다 — 스킬 `model-lab` weekly. 계산은 체계적으로, 리포트 설명은 짧게.

- **텐배거 리포트**(2026-10-29, 2026-10-30 개정 — 주중 매시간, 2026-10-31 위 일정으로 변경): 회차마다 종목 1개를 차트 포함 HTML(outputs/tenbagger/reports/)로 만들고(예약 작업 chiip-tenbagger-report), **발행은 한 묶음**(2026-10-30 마스터 설계 승인 — `scripts/tenbagger/publish_tenbagger.py`): GitHub 보관(HTML·그림이 보이는 마크다운 판 `report_md.py`·데이터) → 보기 링크 = claude.ai 비공개 Artifact(같은 날 마스터 지시 "리포트 링크는 html로" — 비공개 저장소 HTML은 GitHub에서 소스로만 보임) → 노션 Stocks 하위 페이지(HTML 임베드 + 글) → 모두 기록된 뒤 텔레그램 1통(캡션 + 리포트 보기 + 노션 링크, 실패한 단계는 표시 후 다음 회차 재시도). 밸류에이션은 맥킨지·IB 방식 의무: Fiscal.ai 데이터 묶음(컨센서스·가이던스·어닝콜·동종사) → `build_drivers.py` → v2 → `v2_to_report.py --merge`. 자동 삽입 세 절(마스터 지시): **내러티브**(셀·바이사이드·리테일 다각 — 멀티플 프리미엄·리비전 경로, `narrative_view.py`) · **수급 Chiip Flow**(FINRA 공개 자료로 리테일 도매 체결 vs 기관, 이상 거래일 원인, `flow.py`) · **가격 구간**(월·주·일 피보나치 + 50·200일선·거래 범위·라운드 넘버 겹침, `levels.py` — 구간 지표일 뿐 매매 시점 권유 아님). 연구 후보이지 매수 권유 아님.
- **텐배거 리포트 양식**(2026-10-30 마스터 지시): 한 장 요약과 본문의 맨 앞은 **내러티브** — 기업가치를 결정하고 멀티플·EPS 프리미엄을 부여하는 이야기, 왜 열광하나(구조적 체질 변화·고부가 믹스·기술 혁신·M&A·재정정책·CAPEX 낙수효과), 제품·서비스·기술(`narrative_view.lead_section`). 그다음 **배수 사다리**(`scripts/tenbagger/ladder.py`) — 시가총액 $30B 미만 2·3·5·10배, $30B~$100B 2·3·5배, $100B 이상 2배까지, 단계마다 필요 조건(매출 규모·CAGR, OPM 또는 EBITDA Margin, EPS 규모·CAGR — 2026-10-31 마스터 지시)과 어떻게 성장해야 하나·펀더멘털 전망. 그림 고정: 3 = 가격 내포 기대 vs 필요 성장, 5 = 지난 12개월(캘린더) EPS 리비전 추이 + 실적·내러티브 사건별 변화, 8 = 최근 4개 분기 주가 분해(EPS 리비전 × 멀티플, `revision_view.py`). 논문 표기('저자 연도')와 데이터 제공처 이름(Fiscal.ai·Zacks 등 — 재무·컨센서스·어닝콜 스크립트를 가져온 곳, Zacks 표기 포함)은 리포트에 남기지 않는다(렌더러 `scrub`, 구분은 '모델 추정'·'애널리스트 추정'. 다른 기능의 Zacks 표기 규칙은 그대로). 본문 아래 부가 설명(업사이드 기준·차트와 표 주석·읽는 법)은 넣지 않는다 — 예외는 그림 5(그래프에는 선 위 사건 번호만, 점선 없음, 번호별 설명은 그래프 아래)와 몬테카를로 해석뿐. 전문 용어·영어 약자 기관명은 처음 나오는 곳에 괄호로 한국어 풀이(`config/report_glossary.yaml`, Fwd 1Y·P/E·P/B·EBITDA·EPS·멀티플은 풀이 제외 — 2026-10-31 마스터 지시). 내러티브 소제목은 '무엇이 기업가치를 바꾸나'(앞에 '여섯 렌즈'를 쓰지 않는다), 항목에 실행 속도(납품 리드타임, 피어 중앙값 대비·회사 이전 대비 변화율을 엔진이 계산) 포함(2026-10-31 마스터 지시). 재정정책 렌즈는 재정정책(행정부)·행정명령(행정부)·연관입법(의회) 세 줄로 나누고, 앞의 둘에 의회 동의 10점(하원 0~5 + 상원 0~5, 2026-10-31 마스터 지시, `narrative_view.congress_score`). 콜 변화 항목별 주주가치 영향에 확신도 가중 수치를 넣지 않는다. 분기별 서프라이즈는 매출·OPM·EPS(회사가 EBITA Margin을 주요 지표로 쓰면 대체).
- **수주·파이프라인**(2026-10-31 마스터 지시 "기업이 진행 중인 수주 및 파이프라인이 있다면 리스트업을 하고 진척도가 몇 %되며, 실행 속도는 어느 수준이며, 방해 요인이 무엇이며 현 진척도에 따른 수익과 진척도 100% 도달했을 때의 총 수익이 얼마인지"): 배수 사다리 다음 절(`scripts/tenbagger/pipeline_view.py`). 모델은 datapack `pipeline`에 원자료만 쓰고 진척도·계획 대비 속도·수익·합계는 엔진이 계산한다. 확정 수주만 확정 합계에 넣고, 모르는 값은 '미확인'으로 둔다. 재료가 없으면 `--merge`가 멈춘다. 수주가 없는 회사는 `{"none": "이유"}`.
- **노션 Stocks 우선 리포트**(2026-10-30 마스터 지시): 텐배거 리포트는 마스터 요청 다음으로 노션 Stocks 종목 중 **현 시점 ±7일 어닝콜 스크립트 + 컨센서스**를 입력해 둔 종목부터(`scripts/tenbagger/notion_stocks.py` 색인 → `pick_report.py`). 그 페이지의 스크립트·컨센서스를 데이터 묶음에, IB 내용은 라이선스 요지로만 내러티브 셀사이드 층에(문장 복제·목표가 결론화 금지, 외부 공유 금지).
- **멀티플 산정**(2026-10-29): 과거 레인지 → 동종 레인지 → ROIC·성장·이익률 기반 펀더멘털 내재 → 할인 분해 → 합리적 멀티플(`scripts/valuation/v2/multiples.py`, `knowledge/methods/multiples.md`). **기준 멀티플은 이익 지표의 Fwd 1Y·2Y·3Y 세 분류**(2026-10-30 마스터 지시, 그림 3개 — 다음 4개 분기·5~8번째·9~12번째 분기 이익): EPS가 주요 지표면 P/E, EBITDA가 주요 지표면 EV/EBITDA(`multiples.main_metric`), Fiscal.ai 우선(`forward_multiples.js` → `adapter.py --forward-multiples`, 재료가 없으면 `v2_to_report --merge`가 멈춘다). EV/매출은 재료가 없거나 이익이 적자일 때만 이유를 적고 쓴다.
- **발행 알림 양식**(2026-11-01 마스터 지시): `scripts/tenbagger/report_feed.py`가 고정한다. 결론 → 왜 이렇게 보나 → 밸류에이션 → 셀온 조건 → 다음 확인, 사실은 하이픈 줄 하나에 하나.
- **손익비 표기**(2026-11-01 마스터 지시): %가 아니라 ratio로 쓴다. 상승폭 +20%·하락폭 −10%면 2.0이다. 모델이 쓰는 글과 캡션도 같다.
- **목표주가**(2026-11-01 마스터 지시 "현 시점 목표 주가를 월스트리트 IB 리서치 하우스 모델링으로 산정하고 이를 기준으로 업사이드를 측정. 기본 시나리오가 목표 주가라고 생각하면 그것으로, 기본과 강세 사이에 도달할 확률이 높아 보이면 그 사이로. DCF 한 요인에만 의존하지 말고 차트 기법 상승 여력, 내러티브 멀티플 프리미엄 확정 여력까지 반영", 다음 리포트부터): `scripts/tenbagger/target_price.py`가 계산한다. 약세~기본~강세 축에서 시나리오 확률(35%)·DCF 12개월 뒤 값(20%)·차트 상승 여력(20%, 200일선·52주 고점·피보나치)·내러티브 프리미엄 여력(25%)이 가리키는 위치를 가중해 정한다. 업사이드·구매 등급·주가별 업사이드는 목표주가 기준이고, 확률 가중값은 요인 하나로 표에 남는다. 손익비는 그대로 강세 상승폭 ÷ 약세 하락폭이다. 요인에 안 잡히는 판단은 datapack `target_view`에 이유와 함께 쓴다(±0.25 안). Chiip View·요약에서도 업사이드는 목표주가 기준으로 쓴다.
- **목표주가·투자의견 제시**(2026-11-01 마스터 지시 "목표 주가와 투자 의견은 제시하라. 전문 모델링으로 추산한 것이고 최종 판단과 조치는 내가 취한다"): 리포트의 투자의견은 구매 등급이다. 공개 자료 기반 규칙 계산값이고 마스터 포지션을 읽지 않는다. 매매·비중·금액 지시는 쓰지 않으며 '투자 권유 아님' 표기는 유지한다(평가기 규칙 `report-no-personal-order`).
- **주가별 업사이드 막대**(2026-11-01 마스터 지시): 값에 % 단위를 붙인다.
- **리포트 양식 개정**(2026-11-01 마스터 지시): 분기 그림의 EPS는 매출과 같은 분기 축. 주가별 업사이드와 일·주·월봉 지지선은 '주봉 피보나치 61.8% 되돌림 지지선'처럼 풀어 쓴다. 어닝콜 변화에서 실적 vs 컨센서스 표를 뺀다. 수급은 한눈에 보기 그림만 두고 본문 절을 없앤다. 셀사이드·바이사이드·언론은 체크리스트 바로 앞 '시장 평가' 절로 옮긴다.
- **마스터 수동 지시**(2026-11-02 마스터 지시 "수동으로 Chiip Analysis 작성을 시키겠다", "기존에 작성했던 리포트들도 새 양식으로 업데이트해라"): `knowledge/models/tenbagger/report_queue.txt` 한 줄을 `키 | new 또는 reissue | 메모`로 쓴다. 모든 후보보다 먼저 나오고 30일 규칙을 넘는다. `pick_report.py` 출력의 `mode`·`note`를 따른다.
