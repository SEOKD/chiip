# 텐배거 리포트 운영 규칙

> CLAUDE.md '출력 채널'에서 옮긴 마스터 지시(2026-10-31, AAP-20261031-02). 새 지시도 여기에 적는다.

- **텐배거 리포트**(2026-10-29, 2026-10-30 개정 — 주중 매시간): 회차마다 종목 1개를 차트 포함 HTML(outputs/tenbagger/reports/)로 만들고(예약 작업 chiip-tenbagger-report), **발행은 한 묶음**(2026-10-30 마스터 설계 승인 — `scripts/tenbagger/publish_tenbagger.py`): GitHub 보관(HTML·그림이 보이는 마크다운 판 `report_md.py`·데이터) → 보기 링크 = claude.ai 비공개 Artifact(같은 날 마스터 지시 "리포트 링크는 html로" — 비공개 저장소 HTML은 GitHub에서 소스로만 보임) → 노션 Stocks 하위 페이지(HTML 임베드 + 글) → 모두 기록된 뒤 텔레그램 1통(캡션 + 리포트 보기 + 노션 링크, 실패한 단계는 표시 후 다음 회차 재시도). 밸류에이션은 맥킨지·IB 방식 의무: Fiscal.ai 데이터 묶음(컨센서스·가이던스·어닝콜·동종사) → `build_drivers.py` → v2 → `v2_to_report.py --merge`. 자동 삽입 세 절(마스터 지시): **내러티브**(셀·바이사이드·리테일 다각 — 멀티플 프리미엄·리비전 경로, `narrative_view.py`) · **수급 Chiip Flow**(FINRA 공개 자료로 리테일 도매 체결 vs 기관, 이상 거래일 원인, `flow.py`) · **가격 구간**(월·주·일 피보나치 + 50·200일선·거래 범위·라운드 넘버 겹침, `levels.py` — 구간 지표일 뿐 매매 시점 권유 아님). 연구 후보이지 매수 권유 아님.
- **텐배거 리포트 양식**(2026-10-30 마스터 지시): 한 장 요약과 본문의 맨 앞은 **내러티브** — 기업가치를 결정하고 멀티플·EPS 프리미엄을 부여하는 이야기, 왜 열광하나(구조적 체질 변화·고부가 믹스·기술 혁신·M&A·재정정책·CAPEX 낙수효과), 제품·서비스·기술(`narrative_view.lead_section`). 그다음 **배수 사다리**(`scripts/tenbagger/ladder.py`) — 시가총액 $30B 미만 2·3·5·10배, $30B~$100B 2·3·5배, $100B 이상 2배까지, 단계마다 필요 조건(매출 규모·CAGR, OPM 또는 EBITDA Margin, EPS 규모·CAGR — 2026-10-31 마스터 지시)과 어떻게 성장해야 하나·펀더멘털 전망. 그림 고정: 3 = 가격 내포 기대 vs 필요 성장, 5 = 지난 12개월(캘린더) EPS 리비전 추이 + 실적·내러티브 사건별 변화, 8 = 최근 4개 분기 주가 분해(EPS 리비전 × 멀티플, `revision_view.py`). 논문 표기('저자 연도')와 데이터 제공처 이름(Fiscal.ai·Zacks 등 — 재무·컨센서스·어닝콜 스크립트를 가져온 곳, Zacks 표기 포함)은 리포트에 남기지 않는다(렌더러 `scrub`, 구분은 '모델 추정'·'애널리스트 추정'. 다른 기능의 Zacks 표기 규칙은 그대로). 본문 아래 부가 설명(업사이드 기준·차트와 표 주석·읽는 법)은 넣지 않는다 — 예외는 그림 5(그래프에는 선 위 사건 번호만, 점선 없음, 번호별 설명은 그래프 아래)와 몬테카를로 해석뿐. 전문 용어·영어 약자 기관명은 처음 나오는 곳에 괄호로 한국어 풀이(`config/report_glossary.yaml`, Fwd 1Y·P/E·P/B·EBITDA·EPS·멀티플은 풀이 제외 — 2026-10-31 마스터 지시). 내러티브 소제목은 '무엇이 기업가치를 바꾸나'(앞에 '여섯 렌즈'를 쓰지 않는다), 항목에 실행 속도(납품 리드타임, 피어 중앙값 대비·회사 이전 대비 변화율을 엔진이 계산) 포함(2026-10-31 마스터 지시). 재정정책 렌즈는 재정정책(행정부)·행정명령(행정부)·연관입법(의회) 세 줄로 나누고, 앞의 둘에 의회 동의 10점(하원 0~5 + 상원 0~5, 2026-10-31 마스터 지시, `narrative_view.congress_score`). 콜 변화 항목별 주주가치 영향에 확신도 가중 수치를 넣지 않는다. 분기별 서프라이즈는 매출·OPM·EPS(회사가 EBITA Margin을 주요 지표로 쓰면 대체).
- **노션 Stocks 우선 리포트**(2026-10-30 마스터 지시): 텐배거 리포트는 마스터 요청 다음으로 노션 Stocks 종목 중 **현 시점 ±7일 어닝콜 스크립트 + 컨센서스**를 입력해 둔 종목부터(`scripts/tenbagger/notion_stocks.py` 색인 → `pick_report.py`). 그 페이지의 스크립트·컨센서스를 데이터 묶음에, IB 내용은 라이선스 요지로만 내러티브 셀사이드 층에(문장 복제·목표가 결론화 금지, 외부 공유 금지).
- **멀티플 산정**(2026-10-29): 과거 레인지 → 동종 레인지 → ROIC·성장·이익률 기반 펀더멘털 내재 → 할인 분해 → 합리적 멀티플(`scripts/valuation/v2/multiples.py`, `knowledge/methods/multiples.md`). **기준 멀티플은 이익 지표의 Fwd 1Y·2Y·3Y 세 분류**(2026-10-30 마스터 지시, 그림 3개 — 다음 4개 분기·5~8번째·9~12번째 분기 이익): EPS가 주요 지표면 P/E, EBITDA가 주요 지표면 EV/EBITDA(`multiples.main_metric`), Fiscal.ai 우선(`forward_multiples.js` → `adapter.py --forward-multiples`, 재료가 없으면 `v2_to_report --merge`가 멈춘다). EV/매출은 재료가 없거나 이익이 적자일 때만 이유를 적고 쓴다.
