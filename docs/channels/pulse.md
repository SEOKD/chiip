# 펄스·실시간 알림 운영 규칙

> CLAUDE.md '출력 채널'에서 옮긴 마스터 지시(2026-10-31, AAP-20261031-02). 새 지시도 여기에 적는다.

- **실시간 전달 = 텔레그램 개인 봇.** 아침·저녁 브리프는 중단(2026-10-28 마스터 지시). P0·P1은 건별 즉시, 알림마다 '⭐ 노션 기록' 버튼. **5분 펄스**(2026-10-28 지시, 2026-10-29 30분 → 10분, 2026-10-30 10분 → 5분): 한 통에 **숏 리포트**(AI 밸류체인 종목 대상 — 주장별 1차 검증·밸류 판단, `config/short_watch.yaml`)와 **미보도 원문**(논문·보도자료·3자 보도자료·SEC 8-K·미국 정부 문서 — 영어권·국내 언론 어디에도 보도되지 않은 것만, 없으면 '없음', 최대 3건)과 **AI 파이낸싱**(2026-10-29 마스터 지시: 하이퍼스케일러·AI 칩·네오클라우드·전력 발행사의 증자·전환·우선주·채권·사모 신용·SPV·전략적 투자 — 보도 여부 무관, 1차 서류로 조건·참여자·직전 대비 변화, `config/financing_watch.yaml`)와 **알파 레이더**(텐배거 발굴 → 알파 5점 이상) — 영어권·미국 주식 중심, 하나라도 있을 때만.
- **판정 상향·P2 요약**(2026-10-29 마스터 지시): T0 연결이 없어도 AI 밸류체인 대형 거래·AI 자금 조달·프런티어 AI 상장·감시 기업 M&A·주요 매체 단독·보유 종목 관련 사건은 P1(`radar/promote.py`). P2는 매일 08~10시 1통 요약(`radar/p2_digest.py`).
- **수집 범위:** 뉴스는 Reuters·Bloomberg·WSJ·The Information·Business Insider·CNBC·Seeking Alpha·PR Newswire·GlobeNewswire 9곳만(CNBC·Seeking Alpha는 robots.txt가 AI 수집기를 막아 Google News 색인으로만). 중심은 정부 자료(각국 정책·행정명령)·기업 공시·실적 자료·학회·협회. 종목 자료는 **포커스 점수 5.0 이상 + 알파 잠재력 5.0 이상 + 마스터 노션 Stocks + 레이더 테마(데이터센터 전력 55종목, `config/earnings_watch.yaml` radar_themes)**만, 감시 목록 전체의 공시·실적은 항상(`config/focus.yaml`, `radar/pollers/gate.py`).
- **실시간 알림 양식**(2026-10-29 마스터 지시 "뉴스 전달할 때 종목｜내용｜시간 → ☞ 회사 설명(비즈니스 모델, 성장동력, 내러티브 등) 3줄 → 핵심 내용 요약 3개"): ① `종목(종목코드)｜기사｜시간`(기사 제목에 원문 링크) ② `☞ 회사 설명` 한 줄로 이어서(2026-10-30 마스터 지시, `notify.profile_line`) — 비즈니스 모델·성장 동력·내러티브(`config/company_profiles.yaml` 30일 캐시 → 판정 모델 profile → 기업 1줄 + 지금의 내러티브 요약) ③ `• 핵심 내용` 최대 3줄(판정 모델 points, 빠른 길은 haiku 1회, 실패하면 기사 요약문 문장 — 없으면 비움). M&A 기사는 끝에 `• 시너지:` 한 줄(2026-10-30 마스터 지시 — 인수기업·피인수기업의 비즈니스 모델·포트폴리오로 본 효과, 판정 모델 synergy, 펄스·포트폴리오도 같음). 문단 사이 빈 줄. P0·P1 등 등급 코드·지시 번호·'보강 적용'은 텔레그램에 드러내지 않는다(`notify.format_item`·`brand()`). 규칙 건은 모델 판정 전 수집 직후 발송(`run_poll.fast_lane` → `enrich`).
- **펄스 양식**(2026-10-29 마스터 지시 "문단 띄어쓰기·직관적·간결·핵심 빠짐없이"): 건마다 머리줄·**판단**·근거 5줄·링크, 문단 사이 빈 줄, 인사이트 순, 내부 코드는 기록 파일에만(`docs/tasks/chiip-pulse.md` 3단계). 기술·세그먼트·제품·정책·프로젝트 이름은 처음 나오는 곳에 괄호로 풀고 금융 용어는 풀지 않는다(2026-10-31 마스터 지시, `config/pulse_glossary.yaml`·`radar/pulse_gloss.py`). 확신도 표현과 상·중·하 대신 **컨빅션 x/10**(같은 날 지시, `insight_calc.py conviction`). 예약 작업 chiip-pulse는 이 지시서 파일을 읽어 수행한다.
