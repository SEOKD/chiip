# 주가·컨센서스 원천 후보 (BUILD_PROMPT §10.6, §18 6단계 — 마스터 확정 필요)

치입은 아직 주가·컨센서스를 자동 수집하지 않는다(모든 카드의 시장 맥락은 "미확인"). 아래 중 선택해 주시면 수집기를 붙인다.

| 후보 | 범위 | 장점 | 확인할 점 |
|---|---|---|---|
| KRX 정보데이터시스템 / 공공데이터포털 주식시세 API | 국내 일별 시세 | 공식·무료 | 지연(일별)·키 발급·약관 |
| 증권사 Open API (예: 마스터 계좌 증권사) | 국내 실시간·해외 | 실시간 | 계좌·인증 필요 — 키는 마스터가 직접 입력, 주문 기능은 쓰지 않음 |
| 비공식 파이썬 라이브러리(야후 파이낸스 계열 등) | 국내외 일별 | 간편 | 비공식·약관 불명확·중단 위험 — 권장하지 않음 |
| 컨센서스 | 증권사·데이터 벤더 | — | 대부분 유료·라이선스. 마스터가 정당하게 받은 리포트를 ib-digest로 요약하는 방식이 기본 |

정한 뒤: 영향 판정 사후 점검(카드 방향 vs 1일·5일 주가 반응, §17.3 — 학습 목표가 아니라 점검 자료) 가동.
