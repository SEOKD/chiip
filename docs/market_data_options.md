# 주가·컨센서스 원천 후보 (BUILD_PROMPT §10.6, §18 6단계 — 마스터 확정 필요)

치입은 아직 주가·컨센서스를 자동 수집하지 않는다(모든 카드의 시장 맥락은 "미확인").
2026-10-28: 위클리 리뷰에 **글로벌 증시 주간 상승률(Dean's Ticker 형식 — 미국·미국 중소형·유럽·일본·한국)**이 추가되면서 다섯 지역 전 종목의 주간 등락률·시가총액·업종이 필요해졌다.

## 확인 결과 (2026-10-28)
| 후보 | 범위 | 확인한 것 | 판단 |
|---|---|---|---|
| Nasdaq.com 스크리너 API | 미국 | `api.nasdaq.com/robots.txt` 가 전체 `Disallow: /` | **사용 불가**(robots 위반) |

## 치입 권장
1. **상용 글로벌 API 하나**로 다섯 지역을 받는다(수집기 1개, 유지 부담 최소). 고를 때 볼 것: 일본·한국 커버리지, 시가총액·업종 필드, 주간 순위 공개(텔레그램 채널) 허용 여부.
2. 비용을 피하려면: 한국 = KRX OPEN API, 미국·유럽·일본은 상용 API 또는 마스터가 이미 쓰는 원천.
- 마스터가 Dean's Ticker를 만들 때 이미 쓰는 데이터 원천이 있으면 그것을 우선 검토한다.

정한 뒤: ① 주간 상승률 수집기(`config/weekly_movers.yaml` → `knowledge/models/weekly_movers/YYYY-Www.csv`) ② 영향 판정 사후 점검(카드 방향 vs 1일·5일 주가 반응, §17.3) 가동.
