# 주가·컨센서스 원천 후보 (BUILD_PROMPT §10.6, §18 6단계 — 마스터 확정 필요)

치입은 아직 주가·컨센서스를 자동 수집하지 않는다(모든 카드의 시장 맥락은 "미확인").
2026-10-28: 위클리 리뷰에 **글로벌 증시 주간 상승률(Dean's Ticker 형식 — 미국·미국 중소형·유럽·일본·한국)**이 추가되면서 다섯 지역 전 종목의 주간 등락률·시가총액·업종이 필요해졌다.

## 상용 API·Koyfin 비교 (2026-10-28 조사, 마스터 '상용 API 하나' 선택 후)
| 후보 | 다섯 지역 | 주간 순위에 필요한 것 | 가격(개인) | 채널 게시(공개 표시) |
|---|---|---|---|---|
| **Koyfin (마스터 유료 구독 중)** | 미·유럽·일·한 포함 | 스크리너에 1주 등락률·시총·업종 | 추가 비용 없음 | 마스터가 이미 하는 방식 — 약관 판단은 마스터 |
| EODHD 'EOD+Intraday All World Extended' | 한국(KO·KQ)·유럽·미국 확인, **일본·영국은 거래소 목록 API로 확인 필요** | 스크리너 API에 `refund_5d_p`(5거래일 등락률)·시총·섹터·업종 정렬, 요청당 최대 500개 | $29.99/월 | **개인 요금제는 재배포·표시 금지**(약관: "redistributing, displaying, or granting access") → 채널 게시엔 상업 요금제·허가 필요 |
| FMP | 상위 요금제만 전 세계 | 스크리너 | $22~149/월(2차 자료) | 하위 요금제 표시·재배포 금지(2차 자료) |

- **Koyfin은 공개 API가 없다**(여러 2차 자료 일치 — 데이터 공급사 계약 제약). 치입이 마스터 계정으로 로그인해 화면을 자동 조작하는 것은 안전 규칙(로그인 대행 금지)과 약관 위험 때문에 하지 않는다.
- 대신 **마스터가 Koyfin 스크리너 결과를 CSV로 내보내 `radar/drop/weekly_movers/`에 넣으면**, 치입이 지역별 순위·한글 표기·업종을 붙여 위클리 리뷰와 Dean's Ticker 복사용 블록을 만든다. 주 1회, 지역 5개 화면 내보내기.

## 치입 권장
1. **1순위: Koyfin CSV 내보내기 → 치입 정리.** 추가 비용 없고, 채널에 이미 쓰는 데이터와 같아 숫자가 어긋나지 않는다. 마스터 손이 주 1회(약 5분) 든다.
2. 완전 자동이 필요해지면 EODHD(스크리너 `refund_5d_p`) — 단 채널 게시까지 하려면 상업 요금제·허가를 먼저 확인.
3. 한국만 무료로 자동화하려면 KRX OPEN API.

정한 뒤: ① 주간 상승률 수집기(`config/weekly_movers.yaml` → `knowledge/models/weekly_movers/YYYY-Www.csv`) ② 영향 판정 사후 점검(카드 방향 vs 1일·5일 주가 반응, §17.3) 가동.
