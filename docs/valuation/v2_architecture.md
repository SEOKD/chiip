# 치입 밸류에이션 v2 — 설계안 (2026-10-28 마스터 승인 · 1단계 구현 완료, 2단계 대기)

> 마스터 결정: 상승여력은 분포·확률·필요 가정으로만 표기. 2단계 이관 종목 INNIO·SK하이닉스·두산·ServiceNow.

> 마스터 미션: "수집 정보 + 마스터 인사이트를 종합해 텐배거(큰 알파) 종목을 발굴하고, 내러티브·펀더멘털·비즈니스 관점에서 앞으로 얼마나 상승여력이 있는지 판단한다. McKinsey *Valuation* 같은 바이블과 최신 논문으로 현재 시장 역학을 반영한 시의성 높은 모델을 만든다."
> v1(`framework.md`)은 멀티플·리비전·EPS 역DCF 중심의 **"얼마나 반영됐나"** 엔진이다. v2는 그 위에 **"가치가 어디서 나오고(ROIC·성장·WACC), 시장은 무엇을 가정하며(기대 역산), 그 가정이 기저율상 얼마나 그럴듯하고(외부 관점), 결과가 어떤 분포를 갖는가(확률)"** 를 더한다.
> 문헌 근거·검증 상태는 `knowledge/models/lab/notes/20261028_valuation_literature.md`. 2차 자료로만 확인한 수치는 '보도 기준'으로 표시했고, 구현 때 원문으로 다시 확인한다.

### M1 재무 재구성 (McKinsey 방식)
- 영업과 비영업을 분리: **투하자본(IC)** = 영업운전자본 + 순유형자산 + 리스자산 + 기타 영업자산(순) [영업권·인수 무형자산은 별도 표시해 ROIC를 포함/제외 두 가지로]
- **NOPAT** = EBITA × (1 − 영업세율) / **FCF** = NOPAT − 순투자 / **ROIC** = NOPAT ÷ 평균 IC / **재투자율** = 순투자 ÷ NOPAT / 성장 = 신규투자수익률(RONIC) × 재투자율
- 표준 보정: ① R&D 자본화(업종별 상각 연수 사전값: 반도체 5년·소프트웨어 3년 — 현금흐름은 그대로, ROIC·IC만 바뀜) ② SBC는 비용(회사가 제외해도 되돌림) ③ 리스 ④ **감가상각 내용연수 민감도**(GPU 비중 큰 하이퍼스케일러·네오클라우드: 4·5·6년) ⑤ 선수금(테이크오어페이 계약의 음(−)의 운전자본, 예: INNIO) ⑥ 재고 증가·발생액 품질 경고

### M2 예측 — 세 트랙을 결합
1. **동인 트랙(내부 관점)**: 사업부별 물량 × 가격 × 믹스. 물량 = min(수요, 캐파 × 가동률 × 수율). 업종 모듈은 5장.
2. **기저율 트랙(외부 관점)**: 규모(매출 십분위) × 업종 × 출발 성장률별로 매출 CAGR(3·5·10년)·영업이익률 변화·ROIC 변화의 실제 분포. **우리 데이터로 직접 계산**(EODHD 이력 + SEC XBRL, 연 1회 갱신 — Mauboussin 표는 원문 미확인이라 사전값 참고만).
3. **사이클 트랙**: 수요(최종 출하 × 탑재량) vs 공급(캐파 + 경쟁사 증설 반응 — Greenwood·Hanson 경쟁 무시 파라미터) → 가격·가동률. 컨센서스의 추세선 대신 사이클 국면별 확률 가중(McKinsey 경기순환 기업 장).
4. **결합**: 사후 전망 = w(h) × 내부 + (1 − w(h)) × 기저율 중앙값. w는 증거 강도(확정 수주잔고·장기계약·캐파 제약)가 높을수록 크고, 예측 연도 h가 멀수록 반감기로 줄어든다. **컨센서스 장기 성장률은 상위 십분위일수록 기저율 쪽으로 축소**(Bordalo 등 2019: 애널리스트가 정보에 약 2배 과잉반응).
5. **페이드**: ROIC(t) = WACC + 해자 프리미엄 + (ROIC₀ − WACC − 해자) × (1 − λ)ᵗ. λ 사전값 0.38(Fama·French 2000), 해자 등급별 조정(넓은 해자 0.15 / 범용 0.5 — 피팅 대상). 성장은 경쟁우위 기간(CAP) 동안 영구성장률로 수렴.

### M3 가치 엔진
- **기업 DCF(FCFF)**: 명시 10년(정밀 5 + 페이드 5) + **계속가치 = NOPAT_{T+1} × (1 − g/RONIC) / (WACC − g)**. g ≤ 장기 명목성장(미국 ~4%, 한국 ~3%), RONIC 기본값 = WACC(성장해도 가치 창출 없음), 해자가 증명된 경우만 WACC + 스프레드(McKinsey 계속가치 장).
- **경제적 이익(EP) 모델로 항등 검증**: IC₀ + Σ EP/(1+WACC)ᵗ = DCF 값(어긋나면 모델 오류).
- **지분 브리지**: EV − 순차입 − 부채성 항목(리스·연금·소수지분·우선주) + 비영업자산(현금·투자·지분 — 예: 삼성·SK의 계열 지분) → 희석 주식 수.
- **할인율(M7과 연결)**: 자기자본비용 = 무위험금리(매일) + 바텀업 베타(업종 무부채 베타 → 목표 부채비율로 재부채화) × 내재 ERP(월간) + 국가위험(매출 지역 가중). 부채비용은 실제 채권 수익률 또는 합성 등급 스프레드. 통화 일관성(원화 현금흐름 = 원화 할인율).
- **교차 검증**: 정당 EV/NOPAT = (1 − g/RONIC)/(WACC − g) vs 피어 / 메모리 정당 P/B = (ROE − g)/(COE − g) / EV/EBITDA는 설비 강도가 비슷한 피어끼리만 / 복합기업 SOTP − 지주 할인 / 잔여이익(Penman)은 앵커·검산.

### M4 확률 엔진
- **시나리오 나무**: 약세·기본·강세 + 꼬리 시나리오(AI capex 삭감, 메모리 하강, 점유율 상실, 고객 신용 사건). 확률은 증거와 기저율로 정하고 25/50/25 기본값을 쓰지 않는다.
- **몬테카를로**: TAM 성장·점유율·종착 마진·매출/투하자본·WACC를 기저율·시나리오에서 나온 분포로 추출, 상관(예: TAM↔마진 +, 사이클 국면) 반영. 고성장·현금 소진 기업은 **Schwartz·Moon형**(매출 성장률 평균회귀 확률과정 + 마진 수렴 + 현금 고갈 시 파산·증자 경계 — 증자 희석 반영).
- 출력: 가치 분포(P10·P50·P90), **P(가치 ≥ 1.5·2·3·10 × 현재가)**, P(가치 < 0.7 × 현재가), 기대값. 표준 라이브러리로 1만 회(종목당 수 초).
- (선택) 실물옵션: 증설·철수 결정 나무(McKinsey 유연성 장) — 설비 집약 기업.

### M5 기대 역산 (PIE)
- 시장 EV와 같아지는 **내포 매출 CAGR**(마진·재투자 고정), **내포 종착 마진**, **내포 경쟁우위 기간(CAP)** 을 각각 푼다.
- 각 내포값을 기저율 분포에 놓아 **"시장 가정 = 기저율 상위 x%"** 로 표시 → 기대 괴리.
- 내포 자본비용(컨센서스 이익으로 역산) vs 요구수익률 → 기대 초과수익의 근사.
- 새 정보가 어느 **가치 트리거**(매출·비용·투자)를 건드리는지 분해 — `factor_impact.py`(INNIO 테스트에서 만든 요인 분해 도구)를 일반화해 earnings-delta·insight-review와 연결.

### M6 내러티브 → 숫자 브리지 (Damodaran)
- 등록부 내러티브마다 5개 입력 매핑과 '가능 → 그럴듯 → 개연' 시험, 근거 claim id.
- 새 정보 분류: **이야기 붕괴(break) / 변경(change) / 이동(shift)** → 바뀐 입력과 크기 → 재평가.
- 내러티브 강도(레이더)는 과밀 지표로 사용: 과밀할수록 장기 성장 축소를 강하게 적용(P4·Bordalo 등).
- **마스터 Insights** 글은 owner=마스터 내러티브로 같은 브리지를 거쳐 정량화된다(insight-review 4단계의 정식 구현).

### M8 상승여력·알파 합성 (마스터가 원한 출력)
종목 카드 v2의 정량 블록:
1. 기대 내재가치 ÷ 현재가, 중앙값 ÷ 현재가
2. **P(≥2배)·P(≥3배)·P(≥10배)** (3·5년 지평), P(−30% 이하)
3. 비대칭 = E[상방] ÷ E[하방]
4. **2배·10배에 필요한 가정의 기저율 백분위**(필요 매출 CAGR·마진)
5. 기대 괴리 = 내포 가정 vs 우리 기본 시나리오(기저율 백분위 차이)
6. 촉매 밀도·해소 시점(어닝 캘린더·KIND·정책 단계)
7. 내러티브 단계·병목 노출(M6, bottleneck-scan)
- **알파 점수 4요소를 정량으로 대체**: upside ← P(≥2배)·E[V]/P / gap ← 내포 가정의 기저율 백분위 괴리 / asymmetry ← 비대칭·규모·커버리지 / bottleneck ← 병목 노출(판단 + 근거). 가중치는 등록부에서 피팅.
- **표기 원칙**: CLAUDE.md의 목표주가·투자의견 금지를 지켜 '분포·확률·필요 가정'으로 표기한다. 주당 내재가치 숫자를 비공개 카드에 보일지는 마스터 결정(9장).

### M9 학습·피팅
- 등록부에 추가할 파라미터(구현 단계에서 등록): 페이드 λ(해자 등급별), 기저율 표 버전, 장기 성장 축소율(LTG 십분위별), 내부·외부 결합 가중 w와 반감기, 시나리오 확률 보정, 몬테카를로 분산, 경쟁 반응 탄력성(사이클 업종), 지주 할인, R&D 상각 연수, 국가별 영구성장률, CAP 기본값, 감가상각 내용연수 시나리오.
- 백테스트 4종: ① 기대 괴리 → 이후 12개월 초과수익(순위 상관) ② P(≥k배) 보정(브라이어·신뢰도 곡선) ③ 예측 오차(내부·외부·결합 중 무엇이 맞았나 → w 피팅) ④ 우리 유니버스의 ROIC 이력으로 λ 피팅.
- 채택 관문: 가치가중, t>3, walk-forward 표본 외 개선 ≥ 5%, 미세주 제외(P9).
- 매일 `model-lab`이 논문을 읽고 위 파라미터에 대한 제안서를 쓴다(ADR-010 루프).

## 3. 핵심 수식 모음
```
가치 동인:   V₀ = NOPAT₁ × (1 − g/RONIC) / (WACC − g)
DCF:        EV = Σₜ FCFFₜ/(1+WACC)^(t−0.5) + CV_T/(1+WACC)^T
EP 항등:     EV = IC₀ + Σₜ ICₜ₋₁ × (ROICₜ − WACC)/(1+WACC)ᵗ + CV_EP
페이드:      ROICₜ = WACC + m + (ROIC₀ − WACC − m)(1 − λ)ᵗ
결합:        x̂ₕ = w(h)·x_inside + (1 − w(h))·x_baserate,  w(h) = w₀·2^(−h/h½)
LTG 축소:    g_LTG,adj = g_base + s_d × (g_LTG − g_base),  s_d = 십분위별 축소계수(상위 십분위 ≈ 0.5 사전값)
CAPM:        r_e = r_f + β_relevered × ERP + Σ(지역 매출 비중 × CRP)
재부채화:     β_L = β_U × [1 + (1 − t)·D/E]
정당 P/B:    (ROE − g)/(COE − g)
듀레이션:    D = Σ t·PV(CFₜ)/Σ PV(CFₜ),  ΔV/V ≈ −D/(1+r) × Δr
Schwartz·Moon(이산): μₜ₊₁ = μ̄ + (μₜ − μ̄)e^(−κ) + σ_μ ε,  Rₜ₊₁ = Rₜ·e^(μₜ)
```

## 6. 위험과 한계
- **모델 위험**: 계속가치 비중이 60%+(INNIO 테스트 63%)라 WACC·g에 민감 → 민감도 표와 분포를 항상 함께 낸다. 1%p WACC가 한 분기 뉴스 전체보다 클 수 있다(INNIO 테스트에서 확인).
- **기저율의 함정**: 구조 변화(AI capex)는 과거 분포 밖일 수 있다 → 결합 가중 w를 증거(계약·캐파)로 올릴 수 있게 하되, 근거를 기록.
- **데이터 라이선스**: EODHD 개인 요금제·easyconomics 자료는 비공개 산출물에만. 공개 콘텐츠에는 공개 출처 수치만.
- **경계**: invest 모드 — local-only·필드 인텔은 정량 입력 금지. Informations의 채널체크는 정량 근거로 쓰지 않는다.
- 학술 결과는 '추정' 유형. 2차 자료로만 확인한 수치(문헌 노트 표시)는 구현 전 원문 확인.
