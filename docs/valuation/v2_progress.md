# 밸류에이션 v2 진척도 채점표 (2026-10-28 실측)

> 질문(마스터): "밸류에이션 모델이 최신 논문과 McKinsey *Valuation* 같은 전문서 내용을 얼마나 학습했나 — 100% 만점에 몇 %?"
> 먼저 용어: 여기서 '학습'은 기계학습 훈련이 아니다. ① 문헌의 방법을 **설계**에 넣고 ② **코드**로 구현하고 ③ 실데이터로 **피팅·검증**하는 세 단계다. 세 단계를 따로 채점하고, 종합은 설계 20% · 구현 50% · 검증 30% 가중(작동하고 맞는지가 더 중요하므로).
> 실측 근거: `scripts/valuation/v2/` 모듈 11개, 시험 71개 통과, 등록부 파라미터 58개(사전값 53·제안 3·마스터 고정 2, **피팅 완료 0**), 피팅 작업 0, 백테스트 0, model-lab 제안서 0, 컨센서스 입력 0행, SEC 일괄 기저율 미수집.

## 4. 100%까지 남은 일 (영향 큰 순)
1. **검증·피팅(+최대 30%p)**: 기저율을 SEC 일괄(미국 전 상장사)로 다시 계산 → λ·결합 가중·장기성장 축소 피팅 → 확률 보정(브라이어) → 기대 괴리 백테스트. 필요: `SEC_USER_AGENT`, 가격 이력(KRX·Finnhub 키).
2. **M2 동인 트랙·사이클(+약 10%p)**: 메모리·전력 인프라·기판·SW 업종 모듈, 경쟁 증설 반응.
3. **M8 의사결정 보조 3지표(+약 3%p)**: 아래 5절.
4. **M1 영업 측 재구성·M6 내러티브 브리지·M5 CAP(+약 8%p)**.
5. 컨센서스 입력(마스터 노션) 반영으로 동인 성장 경로를 컨센서스와 대조.

## 5. 핵심 루프에 필요한 '3요인' 정량화 설계 (마스터 지시 2026-10-28)
실시간 정보(실적·보도자료·공시) → 알파 점수 ≥ 5.0 감지 → v2 모델 → 세 요인:
| 요인 | 정량 지표(모델 출력) | 정의 |
|---|---|---|
| ① 매수 매력 | **기대 초과수익률** = (E[5년 뒤 가치]/현재가)^(1/5) − 1 − 자기자본비용, **P(5년 연수익 > 자기자본비용)**, 안전마진 = P10 가치/현재가 | 세 값이 기준(등록부 파라미터)을 넘으면 '정량 신호 강함' |
| ② 비중 | **위험 예산 지표**: 몬테카를로 결과로 계산한 켈리 비율(E[log(1+f·R)] 최대화)의 1/4, 하방(P10) 손실, 변동성, 유동성(일 거래대금) 상한 | 교과서 공식의 기계적 결과. 실제 비중은 전체 포트폴리오·위험 성향·세금 등 치입이 모르는 정보가 필요 |
| ③ 상방 | E[가치]/현재가, P(≥2·3·10배), P90/현재가, 10배에 필요한 성장의 기저율 백분위 | 이미 구현(1단계) |
- **경계**: 치입은 투자자문 자격이 없다. 위 지표는 마스터의 판단을 돕는 **정량 근거**이며, 매수·매도 지시나 금액 결정이 아니다(CLAUDE.md의 목표주가·매수 의견 금지 원칙 유지 — 문구는 지표·확률로만).
