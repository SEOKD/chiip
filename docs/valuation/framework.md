# 치입 밸류에이션 시스템 — 방법론·아키텍처 (v1, 2026-10-28)

> 목적: 뉴스 전달에서 끝나지 않고, 새 정보가 **이익 전망(펀더멘털)** 과 **멀티플(내러티브·심리·금리)** 중 어디를 움직였는지, 시장이 그것을 **얼마나 이미 가격에 넣었는지**를 수치로 판정한다.
> 근거: IB 리서치 하우스의 공개적으로 알려진 방법을 원리 수준에서 종합(BUILD_PROMPT §14 — 유료 산출물 복제 금지). 결정 기록 `docs/decisions/ADR-008-valuation.md`.

## 1. 기본 식
`주가 = 이익 전망 × 멀티플`. 멀티플 안에 내러티브·심리·할인율이 섞여 있다. 시스템은 둘을 분리해 재고, 내러티브는 치입 레이더(뉴스·역방향 신호)로 잰다 — **뉴스(레이더)와 리서치(밸류에이션)가 만나는 지점**.

## 3. 아키텍처 — 코드(결정론)와 모델 판단의 분리
```
[L0 수집 · 코드]  radar/markets/valuation_data.py  (run_hourly 30분 → 05:00~06:00, 15:45~17:00 KST 하루 2회)
   EODHD 펀더멘털(추정치·리비전·서프라이즈·멀티플) + EOD 가격 이력 + 수동 컨센서스(manual_consensus.csv)
   → knowledge/models/valuation/snapshots/YYYYMMDD.csv , prices/<code>.csv
[L1~L5 계산 · 코드]  scripts/valuation/engine.py
   L1 펀더멘털·리비전  L2 멀티플·프리미엄  L3 내재가치·내포 기대  L4 내러티브 강도  L5 반영도 종합
   + knowledge/narratives/registry.yaml(키워드) + radar/inbox(레이더 수집 항목)
   + knowledge/models/valuation/scenarios.csv(시나리오 — 모델이 작성)
   → knowledge/models/valuation/latest.csv · latest.json · history/YYYYMMDD.csv
[해석 · 모델]  스킬 valuation-card  (시나리오 작성·내러티브 단계 판정·카드)
   아침·저녁 브리프 '■ 밸류에이션 레이더' ← engine.py --digest morning|evening
   실적 발표(earnings-delta) 후 카드 갱신 / 위클리 리뷰 섹터 표
```
- 원칙: 숫자는 스크립트만 만든다. 모델은 숫자를 해석하고 시나리오·단계를 근거와 함께 쓴다(CLAUDE.md '수집은 결정론적 스크립트, 판단만 모델').
- 데이터가 없으면 그 칸은 비워 두고 "미확인". 결측을 추정으로 채우지 않는다.

## 6. "얼마나 반영했나" — 6가지 측정과 해석
1. **수익률 분해**: `ln(P/P₋ₙ) = ln(EPS_NTM/EPS_NTM₋ₙ) + ln(PE/PE₋ₙ)`. 재평가 몫이 크면 이번 상승은 이익이 아니라 내러티브·심리·금리 몫.
2. **가격 대 리비전 괴리**: 90일 주가 z − 90일 리비전 z. 양수 크면 "리비전보다 앞서 감"(GS 진단 유형).
3. **내포 성장 − 컨센서스 성장**: 역DCF가 요구하는 성장이 애널리스트 전망보다 높을수록 많이 반영.
4. **내포 강세 확률**: (주가 − 약세 가치)/(강세 가치 − 약세 가치). 시나리오가 있을 때만.
5. **정당 멀티플 잔차**: 펀더멘털로 설명 안 되는 프리미엄 = 내러티브 프리미엄 **후보**(사실 아님).
6. **실적 반응 비대칭**: 서프라이즈인데 다음 날 하락한 비율이 높으면 기대 과열.
- 지수는 구성 요소의 유니버스 백분위 평균. 구성 요소 수(n)를 함께 쓰고, n<3이면 "판단 보류".
- **금지 연결**: 반영도 높음 → 하락 예정 / 반영도 낮음 → 저평가 확정. 반영도는 "기대의 높이"이지 방향 예측이 아니다. "시장이 간과했다"는 consensus-gap 절차(컨센서스·가격 내포 기대 확인) 통과 후에만.

## 7. 내러티브 측정
- 등록부 `knowledge/narratives/registry.yaml`: 이야기 1문장, KPI, 바뀌는 모델 변수, 키워드(4개 언어), 기업별 노출, 반증 조건, 근거 주장 id.
- 강도(코드): 레이더 수집 항목(radar/inbox, 국내외 뉴스·보도자료·공시·커뮤니티)에서 키워드 일치 건수. 같은 원출처 재인용이 섞이므로 **강도는 관심의 크기이지 사실의 증거가 아니다.**
- 단계(모델): 강도 추세 + 리비전 전환 + 잔차 프리미엄 + 주가 모멘텀으로 판정하고 이유를 적는다.
  | 단계 | 전형적 모습 |
  |---|---|
  | 태동 | 강도 낮음·가속, 리비전·프리미엄 없음 |
  | 확산 | 강도 상승, 리비전 시작, 잔차 프리미엄 형성 |
  | 컨센서스 | 강도 높음·정체, 리비전이 숫자에 반영, 프리미엄 유지 |
  | 과밀 | 강도·프리미엄 최고, 가격이 리비전 앞섬, 서프라이즈 후 하락 |
  | 소멸 | 강도 하락, 프리미엄 축소, 리비전 둔화 |
  | 붕괴 | 반증 조건 발생 |
