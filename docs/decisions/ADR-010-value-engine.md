# ADR-010 부가가치 엔진 — 인사이트 검토·IB 모델·지속 학습·3대 산출물

- 일자: 2026-10-28 · 상태: **채택(마스터 승인 2026-10-28, A단계 착수)**
- 승인 시 결정: 노션 글 아래 '치입 검토' 기록 — 예(비공개 허브). 텐배거 유니버스 — 치입 추천안(`config/tenbagger.yaml`, 마스터 검토 대기). 데이터 요금제는 ALL-IN-ONE 승인(같은 날, 키 입력 대기).
- 마스터 지시(요지): 치입의 핵심 역할은 실시간 조사 정보와 마스터가 노션에 올린 정보를 종합해 마스터의 투자·리서치 인사이트를 정성·정량으로 체계적으로 평가·검토하는 것. 정량은 월가 IB 밸류에이션 모델링. 모델 아키텍처는 영어권 학계·금융업계 논문·기술 자료를 매일 학습해 고도화(= 파라미터를 만들고 피팅). 존재 이유는 부가가치: ① 세미애널리시스처럼 시장에 영향을 주는 리서치 리포트 ② 기자 본업의 기사 소재 ③ 포트폴리오 알파를 위한 텐배거 후보 지속 발굴. 부가가치의 원천은 "같은 정보로 다른 내러티브·인사이트" 또는 "독점 정보".

## 0. 사명 — 모든 산출물에 붙는 '부가가치 검사'
산출물마다 부가가치 원천을 하나 이상 표시하지 못하면 만들지 않는다.
| 원천 | 의미 | 예 |
|---|---|---|
| 독점 | 남이 못 가진 정보 | 필드 인텔(대조 결과는 로컬만), 역방향 레이더 수렴 |
| 해석 | 같은 정보, 다른 결론 | 양산 엔지니어 관점, 컨센서스와 다른 숫자(variant) |
| 속도 | 먼저 앎 | T0 1차 자료, 상대방 공시 |
| 정량 | 남이 안 하는 계산 | 캐파·BOM 모델, 가격 내포 기대 역산 |

3대 산출물과 성적표(월 1회 점검):
| 산출물 | 형태 | 성적 지표 |
|---|---|---|
| 리서치 리포트 | 월 1편 대표 리포트 + 사건 노트 | 변형 판단(variant call) 적중률, 컨센서스 대비 선행 일수 |
| 기사 소재 | 매일 최대 3건 '야마 후보' 텔레그램 | 마스터 채택률, 타 매체 대비 선행 일수 |
| 텐배거 후보 | 후보 카드 + 가상 추적 목록 | 1·3·5년 수익률 vs 기준지수, 기저율 대비 적중률 |
| (공통) 인사이트 검토 | 노션 글마다 검토 | 마스터·치입 예측의 브라이어 점수(확률 예측 정확도) |

## 1. 인사이트 검토 엔진 (핵심 역할) — 스킬 `insight-review`
입력: 노션 '오피니언·인사이트' DB(마스터 글) + 근거 인텔 relation + 레이더·주장·모델.
1. 분해: 글을 인과 사슬로 쪼개고 고리마다 claim id 연결(없으면 '미확인').
2. 정성 평가(10점, 분리 채점 — CLAUDE.md 10점 평가): 논리 / 사업 경쟁력 / 투자 매력 / 증거 확신도 / 기사 가치 / **신규성(컨센서스와 무엇이 다른가)**. 잘못된 연결 금지표 검사, 가장 약한 고리, 대안 설명(red-team).
3. 정량 평가: 인사이트를 모델 입력 변화로 번역(예: "HBM4 점유율 ○%" → 물량·ASP → EPS) → IB 모델 스택(§2)으로 재계산 → 가격 내포 기대(역DCF)와 비교 → "이 인사이트가 맞으면 가치 차이는 ○%, 시장은 ○%를 반영" → 확률 가중 비대칭.
4. 반증 조건·다음 확인 사건 → `prediction-log`에 측정 가능한 예측으로 등록(마스터 예측 / 치입 예측 구분).
5. 출력: 노션 해당 글 아래 하위 페이지 '치입 검토'(비공개) + DB 속성(정성 점수·정량 갭·판정·검토일). 로컬 상세는 `outputs/report/insight/`.
- 경계: 글에 필드 인텔이 섞이면 invest 판정은 공개 근거로만 하고, 대조 결과는 로컬 파일에만. 공개 게시는 마스터가 직접.
- 주기: 매일 예약 작업이 새 글·수정된 글을 확인. 마스터 요청 시 즉시.

## 2. IB 밸류에이션 모델 스택 (정량)
기존 엔진(멀티플 프리미엄·리비전·수익률 분해·역DCF·반영도) 위에 추가:
| 모델 | 쓰는 곳 | 근거 관행 |
|---|---|---|
| 동인 기반 3표 모델(손익·재무상태·현금흐름) | 커버 종목 | 사업부 물량×ASP×믹스 (`model-build`) |
| DCF(FCFF, WACC=CAPM+국가위험) + 출구 멀티플 교차 | 전 종목 | 할인율 근거: 다모다란 ERP(공개) |
| 사이클 밴드(P/B–ROE 회귀, 정상화 EPS) | 메모리·장비·기판 | 메모리 IB 관행 |
| SOTP − 지주 할인 | 복합기업 | 사업부별 피어 배수 |
| 기대 투자(가격 내포 기대 역산) | 인사이트 검토·텐배거 | Mauboussin·Rappaport 방식 |
| 시나리오 확률 가중 + 민감도 표 | 전 리포트 | `valuation-bridge` |
| 리비전 모멘텀·실적 후 표류(PEAD) 신호 | 포커스 점수·타이밍 | 학계 실증 문헌(재현성 확인 후) |

## 3. 파라미터 등록부와 피팅 — "고도화 = 파라미터를 만들고 피팅"
- `knowledge/models/params/registry.yaml`: 파라미터마다 id·모델·현재값·**사전값(prior)과 출처 논문**·피팅 방법·데이터 구간·마지막 피팅일·표본 외 오차·상태(사전/제안/피팅/채택).
- 지금 코드에 박힌 값(할인율, 섹터별 장기 P/E, 포커스 가중치 0.25×4, 신선도 시한 등)을 전부 등록부로 옮긴다.
- 피팅 하네스 `scripts/fit/`: 시간 순 롤링 검증(walk-forward), 사전값 쪽으로 당기는 축소(shrinkage), 최소 표본, **표본 외 개선이 기준 이상일 때만 채택**. 변경은 `params/changelog.csv`에 남기고 큰 변경은 마스터 승인.
- 피팅 대상 예: 섹터별 장기 P/E·할인율, 메모리 P/B–ROE 기울기, 리비전 신호 반감기, 포커스 4요소 가중치(다음 30일 변동 크기 예측력으로), 텐배거 선별 요인 가중치, 마스터·치입 판단의 보정(calibration).
- **반대 검증(마스터 지시에 대한)**: 매일 피팅하면 작은 표본에 과적합된다. 매일 하는 것은 '학습(논문 읽기·가설 제안)'이고, 피팅·채택은 데이터가 쌓이는 주 1회~월 1회로 한다.

## 4. 지속 학습 루프 — 매일
- 수집(결정론 스크립트) `radar/literature.py`: arXiv API(q-fin 전 분야), NBER 신규 워킹페이퍼, RePEc NEP 주제 목록(재무·회계·산업조직), 연준·BIS·ECB 워킹페이퍼, 다모다란 블로그·데이터 갱신, 공개 실무 리서치(AQR·Alpha Architect 등 메타데이터). 학술지 유료 원문은 초록·메타데이터만(유료벽 우회 금지).
- 판단(모델) 스킬 `model-lab`: 키워드(밸류에이션·주식위험프리미엄·애널리스트 추정·리비전·모멘텀·사이클·멀티배거·머신러닝 자산가격) 상위 1~3편을 구조화 요약(주장·방법·데이터·효과 크기·표본 외 증거·재현 여부) → **제안서**(`knowledge/models/lab/proposals/MLP-*.md`: 어떤 파라미터·모델을 어떻게 바꾸나, 검증 계획) → 데이터가 있으면 백테스트 → 채택 관문.
- 주 1회 '모델 연구 노트'(비공개 Artifact): 무엇을 배웠고, 무엇이 바뀌었고, 표본 외 성과는 어땠나.
- 학술 결과는 '추정' 유형 근거로만 쓴다. 재현 실패 문헌(이상 현상 다수 재현 실패 보고)에 주의.

## 5. 텐배거 발굴 엔진 — 스킬 `tenbagger-screen`, `tenbagger-card`
- 확장 유니버스(포커스 62종목과 별도): AI 하드웨어 밸류체인 한·미·대만·일 중소형주(시가총액 구간은 마스터 결정).
- 발굴 경로 2개: (a) **병목 → 해결 기술 → 작은 공급사**(치입 엣지: `bottleneck-scan` + 역방향 레이더 + 양산 관점) (b) 정량 선별(문헌 사전값으로 시작: 작은 규모, 높은 FCF 수익률·낮은 P/B, 매출 성장 가속, ROIC·총이익률 개선, 재투자 여력, 낮은 커버리지 — 각 요인은 원문 확인 후 등록부에 사전값으로).
- 후보 카드: TAM × 점유율 × 마진 경로 → 5년 이익 → 출구 배수 → 내포 시가총액 vs 현재 → 10배에 필요한 가정과 그 확률, 병목 테제, **킬 조건**, 다음 카탈리스트.
- 가상 추적 목록 `knowledge/models/tenbagger/watch.csv`에 등록일 가격과 함께 기록 → 성과로 선별 요인을 피팅(§3).
- 경계: 연구 후보이지 매수 권유가 아니다. 결정은 마스터. 텐배거는 기저율이 낮다 — 성적은 일화가 아니라 기저율 대비로 본다.

## 6. 리서치 리포트 엔진 (세미애널리시스급)
- 주제 선정 점수 = |치입 추정 − 컨센서스| × 증거 확신도 × 시장 관련성 × 독점성.
- 구조: 결론 → 병목 → 캐파·BOM 숫자(치입 자체 모델) → 가치 이동(누가 유리) → 밸류에이션 함의 → 컨센서스가 가정하는 것 → 반증 조건. 공개판은 public 모드 + 마스터 승인.

## 7. 기사 소재 엔진 — 스킬 `article-pitch`
- 매일 1회(장 마감 후) 텔레그램 1통: 야마 후보 최대 3건 — 신규성·한국 기업 연결·경제적 의미·1차 출처·보강 취재 질문. 역방향 레이더 수렴 신호 우선(독점 각도).
- 텔레그램판은 공개 자료만. 필드 인텔 대조는 로컬 `outputs/article/`만.
