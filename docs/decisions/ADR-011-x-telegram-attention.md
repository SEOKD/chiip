# ADR-011 X·텔레그램 관심도 집계 — 회사명 언급 수만

- 일자: 2026-10-29 · 상태: **채택(마스터 승인 2026-10-29 "허용")**
- 질문(치입): "X·텔레그램 관심도 집계(회사명 언급 수만, 본문 저장 없음)를 허용하시겠습니까?" → 마스터: "허용"
- 배경: 마스터 지시(2026-10-29) "telegram, x, substack, seekingalpha 등 투자 커뮤니티의 투자자 관심도를 잘 트래킹하라". 그때까지 X API·텔레그램 자동 수집은 §21.6(ADR-005)·CLAUDE.md의 제외 원천이었다.
- 개정 위치: CLAUDE.md 컴플라이언스 '제외 원천' 줄, BUILD_PROMPT §21.6 표(개정 주석)·§21.34.

## 1. 결정
Chiip Ten-bagger Discovery 후보·커버리지 종목의 관심도 원천에 X와 텔레그램을 더한다. **세는 것은 회사명이 나온 글의 수뿐**이다.

| 원천 | 방법 | 저장 | 하지 않는 것 |
|---|---|---|---|
| X | 공식 API Counts: Recent(`GET /2/tweets/counts/recent`) — 종목당 하루 1요청, 최근 7일 일별 수 | 날짜·종목·`x`·7일 수 | 글 본문·작성자 조회, 웹 화면 수집(robots.txt 전면 차단), 타임라인 수집(`src-research-x`는 TODO 21-3 대기) |
| 텔레그램 | 공개 채널 웹 미리보기 `t.me/s/<핸들>` — 채널당 하루 1회 7일 거슬러 읽기(요청 사이 1초) | 날짜·종목·`telegram`·언급 글 수(채널 합) | 글 본문·작성자 저장, 봇 API·MTProto(개인 계정)·비공개 그룹, 추측 핸들 |

- 코드: `radar/attention.py`(`x_counts`·`x_count`·`tg_counts`·`tg_channel`·`tg_messages`·`aliases`), 설정 `config/discovery.yaml` `attention.sources.x`·`telegram`.
- 별칭: 영문명·현지명·한국어 표기(`ko`). 영문은 단어 경계, 4자 이하 영문은 제외(오탐). 한·중·일 표기는 부분 문자열.
- 지표 연결: 쏠림(crowding) 백분위의 투자자 원천에 `x`·`telegram`을 넣고, 가속은 다른 원천처럼 같은 원천 4주 평균 대비.

## 2. 비용·한도
- X: 2026-10-29 공식 가격표(pay-per-use) Counts: Recent 요청 1건 $0.005 → 30종목 × 30일 ≈ 월 $4.5. 상한 `monthly_cap` 1,500요청(≈ $7.5)에 닿으면 그 달은 멈춘다(`radar/state/attention_x.json`). 키 `X_BEARER_TOKEN`(D:\local-only\secrets\.env, TODO 21-3과 같은 키) 입력 전엔 건너뛴다.
- 텔레그램: 무료. 2026-10-29 첫 실행 6채널·약 50초.

## 3. 컴플라이언스 근거
- t.me/robots.txt 없음(404, 2026-10-29). 공개 채널 웹 미리보기는 로그인 없이 누구나 보는 화면이다.
- X는 공식 API만. x.com robots.txt가 전체를 막으므로 화면 수집은 계속 금지.
- 개인 식별: 작성자·계정 단위 기록을 남기지 않는다. 채널 목록은 기관·공개 리서치 채널(첫 목록: 하나·키움·신한·SK증권 리서치, IH Research, MojoTrick)이며 개인 신원 추적 용도가 아니다.
- 성격: 관심도는 S1(커뮤니티 신호)이다. 주장(claim)이 아니며 사실로 쓰지 않는다.

## 4. 반대 근거·한계
- 텔레그램 채널이 국내 셀사이드 위주라 한국 종목·한국어 표기에 기운다(첫 실측: 삼성전기 16·Yageo 5, 일본·대만 소형주는 0~1). 해외 투자자 관심의 대리 변수로 쓰면 안 된다 — 원천별 가속으로 본다.
- 셀사이드 채널 언급은 '투자자 관심'보다 '증권사 커버리지 관심'에 가깝다. sellside_events와 겹칠 수 있다.
- X Counts는 동명이칭(예: Delta, Murata)에 약하다 — 질의는 전체 회사명 따옴표로 묶었지만 표본 외 점검 필요.
- 채널이 사라지거나 활동이 멈추면(MojoTrick 마지막 글 2026-08-18) 수가 0이 된다 — 채널 상태(글 수·마지막 글)를 run 메시지와 함께 본다.

## 5. 다시 볼 조건
- X 요금이 바뀌거나 월 상한에 닿으면 요금·대상 축소를 마스터에게 묻는다.
- 4주 기준선이 쌓인 뒤(2026-11-26경) x·telegram 가속이 선별 순위·이후 가격과 연결되는지 model-lab에서 표본 외 점검 — 기여가 없으면 쏠림·가속 계산에서 뺀다.

## 개정 2026-10-31
마스터 운영 채널 딘스티커(d_ticker)는 본문까지 읽는다(`radar/dticker.py`). 다른 채널은 위 결정대로 언급 수만 센다. 에이전트의 채널 발송은 금지하고 `notify.private_chat`이 막는다.
