# ADR-029 종목 범위 확대 4단계 — Analysis 섹터 핵심 지표 절·섹터 데이터 원천 (2026-11-13)

상태: 채택(마스터 지시 2026-11-13 "4단계 진행").

## 맥락
Analysis 리포트 절(공급망 병목·BOM·생산능력·P·Q 사이클)은 하드웨어 제조사 기준이다. 1~3단계로 AI 밖 종목이 리포트 순번에 들어오지만(ADR-025 할당량), 그 회사의 실적을 가르는 섹터 지표(처방·순이자마진·동일 점포 매출·NRR 등)를 담을 자리가 없었다.

## 결정
1. **원천 `sector_data`**(`scripts/tenbagger/sector_data.py`, `config/analysis_sources.yaml`에 등록 → `gather.py`가 모든 종목에 돈다): AI 밸류체인·미분류는 '해당 없음'. AI 밖이면 섹터 판단 틀(ADR-027) 질문 7개를 출력하고, 섹터 공개 데이터를 붙인다.
   - 헬스케어·바이오·의료기기: **openFDA**(api.fda.gov, 키 없음, robots 제한 없음) — 의약품 승인 이력(drugsfda)·의료기기 510(k) 결정. 신청인 이름이 회사 이름과 꼬리가 달라 첫 낱말로 찾고 그 낱말이 든 신청인만. '미검증 데이터'(openFDA 고지) — 회사 공시와 대조.
   - 금융·지역은행: **FDIC BankFind**(api.fdic.gov) — 지주회사 이름(NAMEHCR)이 꼬리를 뗀 뒤 정확히 같은 자회사 은행의 자산·예금·ROA·ROE. 시험에서 'Palomar'가 다른 'Palomar Enterprises' 은행에 잘못 붙어 정확 일치로 바꿨다.
   - 에너지·유틸리티: 기존 eia 원천. 그 밖: 10-K·IR·trade_ppi.
   - **쓰지 않음:** ClinicalTrials.gov API — robots.txt가 `/api/`를 막는다(2026-11-13 확인). 임상 일정은 회사 IR 파이프라인 표·10-K로.
   - 생명과학 도구·계측(MTD 등)은 헬스케어가 아니라 산업재 틀(수주·소모품 반복 매출·가격 전가)로.
2. **리포트 절 '섹터 핵심 지표'**(`scripts/tenbagger/sector_view.py`, `report_layout.py` 커뮤니티 절 다음): datapack `sector_kpis`가 있을 때만. 구조적 우위 점수(틀 7번 질문, 0~10 — 알파 그림자 ADR-028과 같은 기준)를 머리 문장으로, 지표 표(판단 틀 질문 · 지표 · 이 회사 · 동종 · 기간 · 출처), 반증. 숫자가 있는데 출처가 없거나, 반증이 없거나, 없는 틀이면 렌더를 멈춘다. 모르는 값은 '미확인'으로 남긴다. 섹터 틀이 맞지 않으면 `{"none": "이유"}`.
3. 예약 작업 지시(`docs/tasks/chiip-tenbagger-report.md`): AI 밖 종목은 `sector_data` 출력으로 `sector_kpis` 4~7칸을 1차 출처에서 채우고, 판단 카드가 없으면 같은 내용으로 카드도 쓴다(→ 발굴 edge·알파 그림자로 이어진다).

## 효과와 한계
- 4단계로 '발굴(섹터 순환) → 판단 카드 → 알파 그림자 → 리포트 섹터 지표'가 같은 판단 틀 기준으로 이어진다.
- 섹터 데이터는 헬스케어·은행만 공개 API로 자동이고, 나머지는 모델이 공시에서 옮긴다. 더 넓히려면(예: 보험 손해율 NAIC, 소매 동일 점포 매출 모음) 무료·약관 허용 원천을 찾을 때마다 `sector_data`에 더한다.
- openFDA 승인 이력은 '무엇이 승인됐나'이지 매출이 아니다(금지표: 승인 → 매출).
