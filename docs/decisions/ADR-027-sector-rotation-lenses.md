# ADR-027 종목 범위 확대 2단계 — 섹터 순환 스크린·섹터 판단 틀 (2026-11-13)

상태: 채택(마스터 지시 2026-11-13 "2단계 진행"). 수치는 사전값.

## 맥락
ADR-025(1단계)가 섹터 지도·할당량·Pulse 섹터 확장을 넣었지만, 발굴 입력 자체는 여전히 AI 밸류체인 테마 지도와 근거 없는 TradingView 섹션 바구니였다. AI 밖 종목은 '병목 → 해결 기술 → 고객 채택' 틀로는 edge를 매길 수 없어 '① 아이디어'에서 멈췄다.

## 결정
1. **섹터 순환 스크린** `scripts/discovery/sector_rotation.py` + `config/sector_rotation.yaml`
   - 주중 하루 한 번(Ten-bagger 회차의 `--plan`이 `due`일 때) TradingView 섹터 2개씩. 전자기술(AI 지도가 덮음)·기타를 뺀 18개를 약 9거래일(2주)에 한 바퀴. Portfolio 섹터 선정의 신규 편입·편입 후보 섹터를 순번보다 먼저(`group_tv`).
   - 스크리너: 미국, 시가총액 $0.3~30B, 매출 성장 10~300%, 6개월 주가 순 30행. 받은 뒤 30일 거래대금 $5M 미만·장외(OTC) 제외.
   - 점수: 섹터 안 z점수(10·90 백분위로 자른 뒤, ±3 절단) — 성장 0.30·모멘텀 0.25·이익률 0.20·규모(작을수록) 0.15·밸류(EV/매출 낮을수록) 0.10 → 섹터별 상위 5 → `rotation_candidates.json` → 발굴 선별(`screen.py rotation_rows`)에 '섹터 순환: <섹터>' 테마로 합류. 섹터 지도(ADR-025)에도 태그된다.
   - 아시아 스크리너(2026-11-09)와 같은 구조 — 결정론 스크립트가 사양·점수, 모델은 TradingView 호출과 판단만.
2. **섹터 판단 틀 6개** `knowledge/methods/sector_lenses/` — 헬스케어(독점 기간·임상 사건·처방 추세)·금융(ROE − 자본비용·조달 우위·신용)·산업재(잔고의 질·납기·가격 전가)·소비재(가격 결정력·재구매·확장 여지, 기존 consumer_lens 보완)·에너지·소재(원가 곡선 위치·자원 수명·자본 규율)·소프트웨어(NRR·전환 비용·AI 영향). 틀마다 번호 질문 7개 + 지표·원천·흔한 오류·반증 예시, 공통 edge 기준(0~10).
3. **판단 카드** `knowledge/models/discovery/lens_cards/<id>.yaml` — 질문 전부 답(모르면 '미확인'), 1차 출처 URL, 반증, edge. `--card-check` 통과·90일 안 카드만 edge가 선별 점수에 들어간다. 카드가 없으면 edge 5 → 점수가 높아도 '① 아이디어'(선별 통과는 edge 6 이상 + 펀더멘털).

## 근거·한계
- 스크린 점수는 후보를 줄이는 보조다. 경쟁우위 판단은 카드(사람 판단 절차)에서만 — 금지표 '스크린 점수 → 경쟁우위'.
- 6개월 주가 순 정렬은 모멘텀 쪽으로 기운 표본이다(늦게 들어갈 위험). 다음 회차부터 정렬을 바꿔 가며 비교할 수 있게 `sort_by`를 설정에 뒀다.
- 첫 실행(11/13): 헬스케어 기술·금융 각 30행 → 상위 5씩(ETON·XERS·CDNA·AMLX·DCTH / PLMR·SLDE·CLOV·ECPG·VCTR), 모두 카드 없음이라 '① 아이디어'. AMLX는 이익률이 비어 있어 매출 성장 100%가 실제인지 확인 전.
- 등록부 prm-srot-*(가중치·문턱·주기) 미등록 — Chiip 세션 몫.
