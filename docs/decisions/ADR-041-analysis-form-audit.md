# ADR-041 — Analysis 양식 전반 점검·고도화(2026-11-15)

마스터 지시(2026-11-15): "Analysis의 양식 전반에 보완할 부분이 있는지 파악하고 업데이트하라. 추정 모델, 데이터 파이프라인 신뢰성 및 정확도, 피어그룹 선정, 멀티플 프리미엄 산정, 내러티브 정확도 등 전반을 고도화하라."

방법: 세 갈래 읽기 전용 진단(동종사·멀티플 96곳 실제 함수 실행 / 데이터 파이프라인 96곳 / 내러티브 최근 리포트 15건·내러티브 78곳)과 추정 모델 남은 과제(ADR-036)를 함께 봤다. ADR-039(DCF 신뢰 점검·회계연도 시점)·ADR-040(해자 RONIC) 위에서.

## 고친 것
| 영역 | 문제(진단 근거) | 고침 |
|---|---|---|
| 시나리오 가격 | 기본 이익이 사실상 2년 뒤 컨센서스인데 1년 뒤 멀티플을 곱했다 — 77개 리포트 중 22개에서 1.10배 넘게 높고 11개는 2년 뒤 값과 일치, 목표가 10~38% 과대 | `report_layout.case_horizon`: 기본 이익이 맞는 해 h(가장 가까운 컨센서스)를 찾아 h>1이면 h년 뒤 멀티플(동종 h년 뒤 중앙값 ÷ 1년 뒤, 없으면 대상 지금 배수 비율)을 쓰고 h−1년을 자기자본비용으로 할인. 재료가 없으면 멈춘다 |
| 펀더멘털 프리미엄 | 합리적/중앙값이 0.30~8.18배, 75곳 중 29곳이 ±20% 상한에 붙은 스위치. 심리 배율 표본 4곳 미만 11곳 | `multiples.select_multiple`: fund = 상한 × tanh(0.5 × ln(합리적/중앙값) ÷ 상한), 표본 4곳 미만·1/3~3배 밖이면 0 |
| 동종 이상치 | FWONK MSGS 369.9배가 p75를 73.3배로, VSH AOSL P/E 1,028.7 | `multiples.trim_peers`: P/E > 100·EV/EBITDA > 60·EV/매출 > 40 또는 중앙값 1/3~3배 밖은 비교에서 뺀다(행은 남기고 표에 '이상치 제외' 표기) |
| 지금 배수 | Fiscal 스냅숏 배수와 오늘 가격이 섞였다(DELL P/E 0.77배, ATLAS EV +23%) | `multiples.refresh_now`: 엔진 가격으로 P/E(가격÷선행 EPS)·EV/EBITDA((시총+순차입)÷선행 EBITDA, B$ 종목) 다시 잼, 10% 넘게 다르면 바꾸고 표기 |
| 내러티브 단계 | 단계가 목표주가 요인 25%를 움직이는데 자유 문구(PRIM '붕괴 뒤 바닥 다지기')는 0으로 처리. 12/78곳이 리비전과 반대 | `narrative_view.audit`: 여섯 단계 밖이면 막음 · 경고(태동·확산인데 리비전 하향, 소멸·붕괴인데 상향·약화 요인 없음, 요인 상태 밖, 출처 없음) |
| 낡은 내러티브 | CBRS 내러티브 11/7, 콜 11/12, 리포트 11/14 | 콜 날짜 > 내러티브 기준일이면 막음 |
| 리비전 부호 | 적자 EPS가 커진 것을 상향으로(코어위브 5/5 하향인데 +78%) | `revision_pct`: 합이 0 이하·0 근처면 (Σ새 − Σ옛) ÷ Σ\|옛\| |
| 글 점검 | 제목 '시장이 반만 믿는다'(PRIM)가 엔진의 내포 기대(시장이 더 기대)와 반대 · 글 속 시가총액이 기본 주식 기준이라 타일과 −11~−17%(CRWV·VSH·U) | `report_layout.text_checks`: 시장 판단 문장은 숫자 필수, 엔진과 반대면 막음 · 글 속 시가총액이 엔진과 5% 넘게 다르면 '기본 주식 기준' 표기 필수 |
| 표기 | 손익비 143.2·−0.6(CRWV·CBRS) · 저가주 반올림(LPTH $4.3 → '$4') | 강세가 주가 아래거나 약세가 5% 안이면 '손익비 의미 없음' · $20 미만은 소수 둘째 자리 |
| 비용 다리 | CBRS 매출총이익 29.6 → 영업이익 −99.3 사이 막대 없음 · '기타 매출원가 +15.4' | 공시 항목이 빠지면 '영업비용(항목 미공시)' 막대 · 요인 합이 실제 매출원가보다 크면 비례 조정하고 적는다(`cost_bridge_view`) |
| 가격 신선도 | 77/96곳 시세 파일 없음, 15곳 10일 넘게 묵음 | 평가 가격 7일 넘으면 경고, 14일 넘으면 발행 멈춤 |
| 검증기 | 시총 대조가 원자료끼리라 늘 통과(IES 주식 이중 집계 못 잡음) · 비GAAP을 GAAP 칸에(SANM +57%) · 가이던스 없는 회사를 실패로 | `datapack_check`: 기본 주식 × 가격 = 원자료 시총(3%, 주식 종류 사유 있으면 경고) · TTM = 공시 분기 이력(GAAP) · 가이던스 없음 = 경고 · 컨센서스 깊이(3명·다음 해 범위) 경고 |
| 전환사채 | 전환 주식과 원금 차입을 둘 다 셀 수 있었다(VSH 추정 전환 주식 = 기본의 17.6%) | `build_drivers.convert_terms`: 구조화 항목(원금·전환가·결제)이 있으면 내가격일 때만 주식(실물 = 원금 차입에서 뺌, 순주식 = 초과분만) |
| 몬테카를로 | 1년차 성장 충격이 시나리오 혼합과 같은 범위를 한 번 더 더했다 | `montecarlo.within_factor`: σ_within = √max(σ² − σ_between², (0.25σ)²). 영향 작음(P10·P50·P90 ±0.03) |

## 효과(최근 리포트 24종목, 발행 당시 기본 시나리오 대비)
대부분 −2~−10%. 연도 맞춤 BE −29%·EROC −30%, 프리미엄 안정화 FTAI −33%·CBRS −20%·CRL −20%·U −18%, SNDK +33%(믿을 수 없는 합리적 멀티플의 −20% 감점 해제). 새 관문에 다음 렌더 때 걸리는 리포트 6개(낡은 내러티브 AMAT·CBRS, 단계 자유 문구 PRIM·EROC, 글 속 시총 기준 U·VSH, PRIM 제목). 이미 낸 리포트는 다시 내지 않았다.
