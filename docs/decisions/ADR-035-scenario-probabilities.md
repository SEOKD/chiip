# ADR-035 시나리오 확률(약세·기본·강세)을 근거로 계산

- 날짜: 2026-11-14
- 마스터 지시: "Analysis의 밸류에이션 주가 시나리오에서 약세와 강세 확률이 각 25%씩으로 계산이 많이 되는데 이 확률 체계를 다시 점검하라"
- 상태: **구현(2026-11-14)** — `scripts/valuation/v2/scenario_prob.py`, `config/scenario_prob.yaml`, 등록부 `prm-sp-*`, 테스트 `tests/test_scenario_prob.py`

## 1. 점검 결과
| 발견 | 근거 |
|---|---|
| 확률이 네 가지 틀에만 있다 | Analysis 리포트 76건: 25/50/25 35건, 30/50/20 21건, 30/45/25 15건, 35/45/20 5건 |
| 계산이 아니라 지정값 | 리포트 '판단 시나리오' cases `prob`을 모델이 직접 썼다. v2 동인은 datapack `scenario_probs`(74/114가 지정) 또는 어닝콜 톤 규칙(상향 20/50/30·보합 25/50/25·하향 30/50/20) |
| 시나리오 폭과 무관 | 약세·강세 성장률이 기본에서 얼마나 떨어졌는지, 추정치가 얼마나 흩어졌는지가 확률에 들어가지 않았다 |
| 동인 버그 | `build_drivers`가 강세·약세 성장률을 **올해** 컨센서스 최고·최저로 계산해(기본은 다음 해) 15/113 종목에서 강세 < 기본(엔비디아 강세 +4% vs 기본 +73%, LTH 강세 +0.2% vs 기본 +9.8%) |

## 2. 결정
1. **분포에서 자른다.** 다음 회계연도 매출 성장률 g의 분포 F를 만들고, 시나리오 성장률 사이 중간점에서 자른다. P(약세) = F((g약세 + g기본)/2), P(강세) = 1 − F((g기본 + g강세)/2), 기본 = 나머지. 약세·강세는 '그 성장률 근처의 결과 구간'을 대표한다.
2. **내부 관점**: 평균 = 컨센서스 다음 해 성장률, 표준편차 = (최고 − 최저 추정) ÷ 기준 매출 ÷ d2(n) × 1.5. d2(n)는 정규 표본 n개의 범위 기댓값 ÷ σ(통계적 공정관리 관리도 상수 — 애널리스트 n명의 최고·최저로 σ를 추정). 1.5는 추정치 사이 흩어짐이 실제 예측 오차보다 작다는 점을 반영한 사전값(피팅 대상). 범위가 없으면 σ = 5% + 0.25 × |g|(고성장일수록 오차가 크다, 사전값).
3. **외부 관점**: 같은 규모 구간 미국 상장사의 실제 1년 매출 성장률 경험 분포(`baserates.windows(1)`), 가중 30%(참조 집단 예측 — Kahneman·Lovallo 1993, Mauboussin 2016 기저율; 이 저장소 baserates.py가 이미 인용). **SEC 전 상장사 일괄 표본(`sec_bulk.py`)이 생기기 전에는 끈다** — 지금 표본(AI 밸류체인 생존 40종목)은 10억$ 미만 중앙값이 +47%로 고성장 쪽에 치우쳐 있다.
4. 0.05 단위, 각 5% 이상. 모델은 datapack `scenario_probs`에 이유와 함께 시나리오마다 ±10%p 안에서만 조정한다(이유 없으면 엔진 값).
5. 한 곳에서 적용: `run.load_company`가 `scenario_prob.apply`로 동인 확률을 바꿔 DCF 시나리오·몬테카를로·리포트가 같은 확률을 쓴다. 리포트 `scenario_build`가 cases `prob`을 이 값으로 바꾸고 밸류에이션 절에 '시나리오 확률: …' 근거 한 줄을 넣는다.
6. 동인 버그 수정: 강세·약세 범위는 다음 해 최고·최저로, 순서(약세 < 기본 < 강세)가 맞지 않으면 ±40% 규칙. 순서가 틀린 기존 동인은 '계산 불가'로 표시하고 기존 확률을 둔다 — 다음 `build_drivers` 때 고쳐진다.

## 3. 결과(2026-11-14, 동인 116개)
- 계산 100개, 계산 불가 16개(버그 동인 — 재생성 대기). 엔진 확률 조합 32가지(그전 리포트 4가지). 가장 흔한 30/40/30이 24개.
- 기본 확률이 50%보다 낮게 나오는 경우가 많다 — 시나리오 성장률 간격이 실제 1년 예측 오차보다 좁으면 결과가 약세·강세 구간에 떨어질 확률이 커진다는 뜻이다.

## 4. 한계·다음
- 확률은 매출 성장 한 축만 본다(마진 시나리오는 그 매출 구간의 대표값으로 둔다).
- 1.5·5%·0.25·30%는 사전값 — 리포트 원장의 다음 해 실제 매출이 약세·기본·강세 구간 어디에 떨어졌는지로 브라이어 점수를 매겨 피팅한다(등록부 prm-sp-*).
- 외부 관점은 `py scripts/valuation/v2/sec_bulk.py`(SEC 전 상장사 연간 매출, 약 1GB 내려받기) 뒤에 켜진다.
