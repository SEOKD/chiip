- 마스터 지시: "Chiip Model Laboratory 시스템을 더욱 고도화할 수 있는 방법을 고안해 반영하라"
- 상태: **구현(2026-11-08)**

## 2. 결정
1. **의사결정 가치**(`scripts/lab/sensitivity.py`): 상수 하나를 ±10% 흔들어 v2를 표본 종목에 다시 돌리고, 가치/시총 변화·매수 매력 신호가 바뀐 비율·기대수익 변화로 순위를 낸다(정보의 가치, Howard 1966의 단순판). 연구·그림자 후보를 이 순위로 고른다.
   - 첫 결과(10종목): v2 상수 23개 중 효과가 있는 것은 2개뿐(`neutral_p_beat` 신호 5% 변경, `g_term US` 가치 0.2%). ERP·페이드 속도 등은 이 표본에서 결과를 바꾸지 않았다 — 종목 동인이 값을 덮어쓰거나 시장 국면 값이 대신 쓰이는 것으로 보인다(연결 확인 필요). 효과 0인 상수는 연구 대상에서 내린다.
2. **그림자 운영**(`scripts/lab/shadow.py`): 제안 값(도전자)을 실전 산출을 건드리지 않고 매일 전 종목에 현행과 나란히 돌려 기록하고, 일별 밸류에이션 기록의 가격으로 h=20·60 거래일 뒤 순위 정보계수(IC)와 '강함' 신호 초과수익을 낸다. 현행보다 IC가 높고 관측 30·날짜 8을 넘긴 도전자만 stepwise 관문으로 넘긴다.
   - 첫 도전자 2개: `prm-v2-gterm-us`=0.03(현행 0.035), `prm-v2-dec-neutral-p-beat`=0.45(현행 0.5). 2026-11-08 첫날 60종목 × 3모델 기록.
3. **제안 보드**(`scripts/lab/pipeline.py` → `knowledge/models/lab/pipeline.md`): 제안마다 상태·막힌 곳·다음 행동·의사결정 가치·대기 일수·판정일. 일일 회차는 새 제안을 늘리기 전에 **막힌 곳 하나를 그날 푼다**.
4. 주말 회차는 주중 미독 상위를 읽는다.

## 3. 일정
- 매일: shadow run · pipeline · 논문(의사결정 가치 상위·막힌 제안 우선)
- 일요일: sensitivity · shadow score
- 첫 그림자 판정 가능 시점: 가격 20거래일 뒤(2026-12 초), 관측·날짜 기준을 넘길 때

## 4. 한계
- v2 평가기만 붙었다. 알파·텐배거 등급·포커스 모델 상수는 평가기를 붙여야 민감도·그림자에 들어간다.
- 국소 민감도(한 번에 하나)는 상호작용을 못 본다.
- 그림자 IC는 표본이 작으면 흔들린다 — 관측·날짜 문턱이 그래서 있다.
