# ADR-039 — Analysis 밸류에이션 모델 신뢰성 고도화(2026-11-14)

마스터 지시(2026-11-14): "Analysis의 Valuation Model을 점검하라. 모델의 신뢰성을 높이기 위해 고도화할 부분이 있으면 고도화하라."

ADR-036(같은 날, 추정 모델링 전반 재점검)이 고친 30건 위에서, 동인이 있는 122종목 전체에 v2 DCF를 다시 돌려 **종목 사이에 반복되는 결함**을 찾았다(진단 스크립트는 읽기 전용, 결과는 아래 표).

## 진단(122종목, 2026-11-14)

## 고친 것
1. **DCF 신뢰 점검**(`scripts/valuation/v2/run.py quality`) — `dcf_quality {status, usable, flags, warns, exit}`.
   - 산정 불가(usable False): 시나리오 **입력** 순서가 깨짐 · 계속가치 해 NOPAT ≤ 0 · 기본 지분가치 ≤ 0.
   - 주의(쓰되 표시): 입력은 바른데 **가치** 순서가 뒤집힘(투하자본수익률 < 자본비용이면 성장이 가치를 깎는다 — 경제적으로 맞을 수 있어 막지 않는다) · 계속가치가 기업가치의 150% 초과(`dcf_quality.cv_warn`, prm-v2-dcfq-cv).
   - 출구 배수 경고는 `exit`으로 따로 — 업종 범위가 대조 전이라 리포트 본문에는 싣지 않는다(엔진 카드에만).
2. **산정 불가면 DCF를 판단에서 뺀다** — 목표주가 요인에서 DCF를 빼고 나머지 비중을 다시 맞춘다(재료 없는 차트 요인과 같은 규칙, `target_price.build`) · 등급은 교차 확인을 못 하므로 **Strong Buy를 주지 않고**, Buy는 DCF 조건 없이 업사이드·손익비로만(`report_layout.rating` = `rating_ledger.rule`, `buy_call.regrade` 같은 규칙) · 합리적 멀티플(펀더멘털 조정)에서 DCF 내재 배수를 뺀다(`multiples.analyze(dcf_ok)`) · 본문은 "DCF는 목표주가와 등급에 쓰지 않았다 — 사유".
3. **회계연도 할인 시점**(`scripts/valuation/v2/fiscal.py` → `dcf.value(fy_offset)`) — 평가일(시세 날짜)부터 rev0 회계연도 끝까지의 거리(년). 남은 해 몫의 현금흐름을 더하고, 1년차 이후는 제때(평가일 기준 연중) 할인, 이미 끝난 해면 1년차 중 지난 몫은 뺀다. 0이면 예전 계산과 똑같다(시험으로 확인).
   - 회계연도 끝: 동인 `fy_end` → `config/fiscal_year_end.yaml`(SEC submissions `fiscalYearEnd` 106곳, `--sync`) → SEC 10-K → 통화 기준 지역 기본값(엔화 3월, 그 밖 12월, '추정'). MTG(9월 결산)·TOWA·타카라토미는 손으로 넣었다(원문 대조 필요 표시).
   - rev0 회계연도: provenance(FY2026·가이던스·TTM) → 없으면 컨센서스 해 매출과 2% 안 일치(손으로 만든 AMAT 동인).
   - 해석이 의심스러우면(평가일 −0.75년 ~ +1년 밖) 보정하지 않는다(prm-v2-fy-range).
4. **옛 동인 16개 재생성**(자동 생성 파일만, 백업 후 `build_drivers`): 브로드컴·엔비디아·WDC·씨게이트·코히런트·Argan·Atlas·Solaris·Aehr·MVIS·Riot·Vishay·TOWA·CRL·LPTH·NPK. 손으로 만든 동인은 건드리지 않는다 — 깨지면 관문이 '산정 불가'로 막는다.
5. 곁가지(같은 날 내 코드의 결함): Pulse 본문 관문 출력이 cp949 콘솔에서 줄표(—)로 멈출 수 있던 것(`run_poll.body_gate`), 폭포 그림 시험이 앞에 붙은 값 표시 칸을 못 받던 것.

## 효과(122종목)
- 신뢰 점검: 정상 116 · 주의 4(Atlas·BKSY·FRVO·LPTH) · 산정 불가 2(CIFR·MVIS — 지분가치 ≤ 0).
- 시점 보정 100종목 적용, 기본 DCF 중앙값 −1.4%(최소 −54% Atlas — 순차입이 시총의 94%라 기업가치 몇 %가 지분가치 절반, 최대 +4%).
- 11/13~14 리포트 종목: 기본 DCF 변화 −1~−3%p(LTH −68% → −69%, AMAT −29% → −32%). 브로드컴 약세·강세 0.21·0.25배 → 0.78·6.61배, 엔비디아 0.43·0.53배 → 0.69·3.69배.
- 이미 낸 리포트는 다시 내지 않았다(등급·목표주가 변경은 마스터 판단). 다음 렌더부터 반영된다.

## 남긴 것(다음 고도화 후보 — 근거를 더 모은 뒤)
- **계속가치 RONIC**: 지금은 해자 1차 근거가 있는 4종목만 RONIC > WACC. 리포트 해자 판정(`datapack.moat.items`)을 D6 해자 점수로 잇는 방안 — 단 멀티플 선정의 해자 프리미엄·펀더멘털 조정과 겹치지 않게 설계해야 한다(이중 계산). 업종 출구 범위(`valuation_v3.yaml exit_check.ranges`)를 Damodaran 업종 EV/EBIT 표로 대조하는 일이 먼저다.
- 전환사채·옵션 희석(자기주식법·전환 시 차입 제외) — ADR-036 남긴 것 2번.
- 몬테카를로 이중 잡음 — ADR-036 남긴 것 3번.
- 일본·한국 종목 회계연도 끝을 회사 공시로 대조(지금은 통화 기본값 + 3곳 수기).

## 근거
- McKinsey(Koller·Goedhart·Wessels) Valuation 7판 — 연중 할인 관행, 계속가치 RONIC = WACC 기본 가정.
- McKinsey Quarterly "A long-term look at ROIC"(2006) — 중앙 ROIC가 장기 자본비용과 비슷하고, 진입 장벽이 있는 업종은 높은 ROIC가 지속된다(계속가치 RONIC을 해자 근거와 묶어야 하는 이유).
