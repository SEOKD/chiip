# ADR-009 실시간 전환·포커스 종목 점수·노션 아카이브

- 일자: 2026-10-28 · 상태: 채택(마스터 지시)
- 맥락: 뉴스를 실시간 전달하는 에이전트는 흔하다. 치입의 차별점은 1차 자료(정부·공시·실적·학회)와 해석이다. 전 밸류체인 종목을 다 보면 토큰이 낭비된다.

## 결정
1. 아침·저녁 브리프 중단. P0·P1은 텔레그램 건별 즉시(묶음 폐지).
2. 뉴스는 7개 매체만 저장(수집 관문). 국내 언론 검색 중단. SEC EDGAR 공시·실적 수집 추가.
3. 포커스 점수(10점, 4요소, 기준 5.0) 이상 종목만 종목 자료 수집. 매일 06:40 갱신·변화 텔레그램.
   - 4요소 해석: '추적 가치' — 상방·하방 어느 쪽이든 크게 움직일 여지가 있으면 높음(멀티플은 극단적 프리미엄·디스카운트 모두 높음). 마스터가 다르게 원하면 `scripts/focus/score.py` quant_components와 스킬 기준표를 바꾼다.
   - 계산(코드)과 판단(모델)을 섞되 출처를 표시('판'). 판단은 이유·근거 필수.
4. 노션 비공개 허브(인텔 아카이브·오피니언·인사이트). 텔레그램 ⭐ 버튼 → 대기열 → API(토큰 있을 때) 또는 커넥터(예약 작업).

## 대안과 기각 이유
- 점수 없이 고정 감시 목록: 관심 이동을 못 따라감.
- 점수를 전부 모델로: 매일 62종목 전수 판단은 토큰 비용 큼 → 계산 가능한 부분은 코드, 모델은 공백·변화분만.
- 노션 공개 사이트에 바로 기록: 라이선스(EODHD 재배포 금지)·원문 복제·필드 인텔 혼입 위험 → 비공개 허브.

## 남은 결정(마스터)
- NOTION_TOKEN(내부 통합) 입력 여부 — 없으면 ⭐ 기록이 하루 1회(06:40) 반영.
- SEC_USER_AGENT(연락처 포함) 입력 — SEC 접속 규칙 권장.
- always_include(점수와 무관한 고정 종목), 기준점·가중치 조정.
- 첫날 점수(2026-10-28)는 가격·추정치(EODHD) 없이 언급 수·내러티브 강도 + 모델 판단 위주라 확신도 낮음.
