# ADR-024 관심 종목 편입 기준·유지 심사 (2026-11-13)

상태: 채택(마스터 결정 2026-11-13). 문턱은 사전값이며 표본 외 검증 전이다.

## 맥락
마스터 결정: 보유 종목은 EROC·INIO 2개(섹터 보호도 이 둘의 섹터만, ADR-023). 관심 종목(config/portfolio.yaml `status: 관심`) 수에는 상한을 두지 않는다. 대신 평가 기준을 까다롭게 적용해 관리한다 — 편입은 여러 조건 동시 충족, 주기적 유지 심사, 경고 2회 연속이면 제외 후보, 제외는 자동 삭제가 아니라 마스터 보고·승인 뒤 반영. Daily에는 변화가 있을 때만 한두 문장, 주간 리뷰에 전체 심사표.

## 결정 (`scripts/portfolio/watch_review.py`, `config/watch_review.yaml`)
**편입 기준 — 전부 충족, 미확인도 불통과**
| 기준 | 문턱 | 근거 |
|---|---|---|
| 알파 | ≥ 7.0 | 마스터 지시 2026-11-07 '알파 7점 이상' 그대로 |
| 리서치 | 90일 안 Analysis 리포트 또는 v2 밸류 동인(drivers.yaml) | 판단 근거 없이 목록에 올리지 않는다. 90일 = 실적 한 분기 |
| 시가총액 | ≥ $1B | 종합 9.5 명단 TradingView 스크리너 하한과 같은 잣대 |
| 유동성 | 20거래일 평균 거래대금 ≥ $10M | 하루 거래대금이 작으면 가격 신호(알파·밴드)가 잡음에 묻힌다. 업계 소형주 스크리닝에서 흔한 하한 쪽 값(추정) |
| 실적 확인 | 최근 어닝콜 120일 안 | 분기(약 91일) + 발표 지연 여유 |
| 반증 조건 | tenbagger watch.csv kill_conditions 또는 리포트 '반증:'·'킬 조건' | CLAUDE.md 원칙 — 결론에는 반증 조건을 붙인다 |

**유지 심사 — 주 1회(ISO 주차당 한 번, 같은 주 재실행은 횟수 불변)**
경고: 알파 < 7.0(실적 점검 편입분은 자기 alpha_floor) · 직전 심사 대비 알파 1.0점 이상 하락 · 테제 훼손(킬 발동) · 장기 무변화(리포트·데이터팩·종목 장부·알파 산정 중 마지막 새 정보가 30일 넘음) · 편입 기준 미충족. **미확인은 경고가 아니라 메모**(없는 숫자로 빼지 않는다).
판정: 경고 없음 '통과' / 경고 '경고' / 서로 다른 주 2회 연속 경고 '제외 후보'.

**제외** 자동 삭제 없음. 제외 후보를 목록·사유로 마스터에게 보고하고, 승인되면 마스터 세션이 `watch_review.py --apply <id …>`로 `status: 종료` + `ended_reason`(지우지 않음). 예약 회차는 `--apply`를 쓰지 않는다. 마스터 지정(`pin: true`)도 같은 심사를 받되 표에 '마스터 지정'으로 표시한다.

**기존 자동 와치리스트(`scripts/portfolio/watchlist.py`) 변경** 상한 8 → 없음. 자동 편입은 위 편입 기준을 모두 통과한 종목만(못 채우면 '편입 후보'로 기록). 기존 자동 제외(기준 미달 3일 연속·킬 즉시)는 반영하지 않고 '제외 후보'로 `radar/state/watch_proposals.json`·watchlist_log.csv에 남긴다. 실적 발표 알파 점검 편입(earnings-sweep)은 그대로 두고 주간 심사로 거른다.

**출력** Daily `■ 관심 종목 변동`(심사 결과가 바뀐 주에만, `--daily`) · 주간 리뷰 전체 심사표(`--table`) · `knowledge/models/portfolio/watch_review_latest.json`·`watch_review_log.csv`.
