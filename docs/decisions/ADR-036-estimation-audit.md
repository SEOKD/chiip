# ADR-036 — Analysis 추정 모델링 전반 재점검(2026-11-14)

마스터 지시(2026-11-14): "Analysis 리포트의 추정 모델링 전반을 재점검하라. 보완할 부분이 있으면 보완하라."

## 방법
세 갈래로 나눠 코드를 읽고 실제 datapack(us-lth·co-amat 등)으로 수치를 재현해 확인했다 — ① 밸류에이션(DCF·시나리오·확률·몬테카를로·WACC·목표주가) ② 멀티플·P·Q 사이클·EPS 리비전 ③ 거시 지표 싱크로율·자산 구성/ROIC 추정·운영 지표. 발견 30건 중 숫자를 실제로 틀리게 만드는 것부터 고쳤다.

## 고친 것
| 영역 | 문제 | 고침 |
|---|---|---|
| 목표주가(report_layout) | EV 배수(Fiscal.ai EV = 시총 + 차입 + **리스** − 현금)를 지분으로 바꿀 때 리스를 빼지 않았다 — LTH 리스 $2.81B, 주당 약 $12 과대 | v2 동인 순차입(리스 포함, leases.apply)으로 뺀다 |
| 목표주가 | 주식 수 = 시총 ÷ datapack 가격 — 시세 파일이 더 새로우면 주식 수가 틀렸다(13종목, AVGO 1.24배) | v2 market.shares |
| 멀티플(multiples) | 시장 EV는 리스 제외, DCF EV는 리스 포함 — 내재 배수·합리적 가치가 부풀었다(LTH 0.26배 시총) | 같은 순차입 |
| 멀티플 | 장부가가 없는 동종(자본잠식)을 시장 레인지에서도 뺐다(LTH 8곳 → 4곳, 선정 배수가 좁은 상단에 걸렸다) | 레인지엔 남기고 심리 배율에서만 뺀다 |
| 멀티플 | P/E 내재 배수를 EV 비율로 냈다(차입 종목에서 틀림) | P/E는 시총 ÷ DCF 지분가치 |
| 시나리오(build_drivers) | 컨센서스 최저·최고를 목록 위치로 찾았다 — rev_low가 다른 해부터면 2년치 성장을 1년치로(Amkor 강세 50%) | 같은 회계연도 키 |
| 시나리오 | 성장 덮어쓰기를 강세·약세·확률 뒤에 적용 → 강세 < 기본(jp-towa·us-riot) | 덮어쓰기 먼저, 순서 깨지면 ±40% |
| 확률(scenario_prob) | 모델 조정 후 기본 확률이 음수가 될 수 있었다 | 하한 밑이면 약세·강세를 비율로 줄인다. 출처 문구가 조정값을 '근거 계산'으로 적던 것도 고침 |
| 외부 관점(scenarios) | 전 상장사 표본이 없을 때 생존 종목 표본(고성장 치우침)으로 4년차 이후 성장을 끌어올렸다(LTH 10년차 5.9% → 13.1%, 가치 +9.6%) | 전 상장사 표본 전엔 끈다(scenario_prob와 같은 관문) |
| 5년 뒤 가치(dcf.equity_at) | 기존 순차입까지 WACC로 불렸다(레버리지 종목 5년 뒤 가치 과소, LTH 0.07배 시총) | 기존 차입은 세후 차입금리, 더 빌린 몫만 WACC |
| 싱크로율(sync_view) | 작은 기저의 +535% 한두 분기가 r 0.92를 만들었다. 선행을 전체 표본에서 고른 뒤 표본 밖 검증. t ≥ 2는 다중 비교 무보정 | 지표 증가율 양 끝 10% 자르기·순위 상관 동반·t ≥ 2.6, 표본 밖 검증 안에서 선행 다시 고르기, 외삽 범위도 자른 범위 |
| 싱크로율 | 지표 자기회귀 예측을 늘 한 걸음 — 필요한 분기(다음 분기 − 선행)와 어긋났다 | 걸음 수를 세어 그 걸음의 예측 |
| P·Q(pq_view) | 가격 지표보다 먼저 나온 실적 분기를 버렸다(AMAT 4Q 물량 18%p 낮게) · 나우캐스트 창을 달력 분기로 | 실적 분기는 관측값 · 회사 분기 끝 달 |
| P·Q(pq_forecast) | 컨센서스 오차를 거의 끝난 올해 범위 ÷ 4로 잡아 바닥값만 남았다 | 시점에 맞는 회계연도 범위 ÷ d2(애널리스트 수) |
| 자산·ROIC(asset_roic_view) | 유형자산 이월에 처분·재임차 잔차가 없어 과대(AMAT +13.6%) · 감가율 맞춤(평균 잔액)과 적용(기초)이 달랐다 · GAAP 마진이면 인수 무형 상각 누락 · 추이와 표가 다른 투하자본 | 이월 잔차(최근 4개 분기 평균) · 기초 잔액으로 맞춤 · GAAP면 상각 되더함 · 표도 분기 이력으로 |
| SEC 개념(asset_pack) | 범위가 다른 개념(선급 ⊃ 선급비용 등)을 날짜별로 섞을 수 있었다 · 매입채무 포함 합계 칸이면 매입채무 이중 차감 | 이름만 바뀐 개념만 합친다 · 합계 칸이면 매입채무를 뺀다 |

상수: `sync_view.WINSOR` 0.10, `T_SIG` 2.6(registry prm-sync-winsor·prm-sync-tsig).

## 남긴 것(다음 고도화 후보)
- 기준 매출 rev0가 진행 중 회계연도 컨센서스면 그해 현금흐름을 건너뛴다(AMAT FY27, 약 7% 과대) — TTM 또는 마지막 완료 연도에서 출발하고 부분 기간 할인을 넣는 구조 변경.
- 전환사채를 주식과 차입에 이중 반영, 옵션은 총량(자기주식법 없음).
- 몬테카를로가 시나리오 혼합 위에 성장 잡음을 다시 얹어 꼬리가 넓을 수 있다(의도 여부 확인 필요).
- 컨센서스 분기 키(quarters_est)에 기간 끝 날짜가 없어 회계·달력 표기가 섞인 종목(NVDA·ACMR·MPWR)에서 분기가 어긋날 수 있다 — 키마다 끝 날짜를 저장.
- HP 필터 끝점 보정이 컨센서스 성장을 8개 분기 늘여 붙인다(평균 회귀 없음).
- EPS 리비전 그림 5·8이 회계연도가 달력과 다른 종목에서 조용히 빈다(AMAT).
- 세그먼트 → 전사 환산 범위가 다른 세그먼트 분산을 빼 좁다. ops_view CAPEX 결측이면 FCF = OCF.
