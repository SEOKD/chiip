# ADR-020 산업 리포트 고도화 — 세그먼트 귀속 + IB 사고 논리 층

- 날짜: 2026-11-08
- 마스터 지시: "NAND·스토리지 3분기 결산 리포트를 보면 스토리지(낸드) 사업이 전체 매출의 믹스로 잡히는 삼성전자, SK하이닉스, 마이크론은 세그먼트별 실적을 분류해서 봐야지. 이 구조를 앞으로 산업 리포트 쓸 때도 반영하라. 분기 결산 리포트를 포함한 산업 리포트 양식이 사고 논리가 부실하다. IB 리포트 양식과 월스트리트 등 금융기관의 기술 자료와 논리 구조를 참조해 고도화하라."
- 상태: **구현(2026-11-08)** · ADR-018(분기 결산)을 고친다

## 1. 진단 — 1차 시험판의 두 결함
| 결함 | 근거 |
|---|---|
| 겸업 회사 전체 매출을 산업 매출로 셌다 | Micron 3분기 매출 $54.2B 중 NAND는 $14.1B(26%), D램이 $39.8B(73%). '매출 두세 배'의 대부분은 D램이었다. 전업 NAND 회사(SanDisk·키옥시아)는 구성에서 빠져 있었다 |
| 서술은 있는데 논리 구조가 없다 | 결론이 숫자 나열로 시작하고, 시장 견해와 Chiip 견해가 어디서 갈리는지·무엇이 판가름하는지·가격에 무엇이 들어 있는지가 따로 없었다. 인과의 어느 고리가 약한지도 표시되지 않았다 |

## 2. 결정 A — 세그먼트 귀속(`config/industry_segments.yaml`, `radar/industry_segments.py`)
- 산업 = 제품으로 정의한 **매출 풀**(NAND 플래시·HDD·D램 …). 산업 매출 = 회사별 그 사업부 매출의 합(IB 메모리 모델의 공급사별 NAND 매출 합산과 같은 방식).
- 회사마다 노출도(사업부/전사)와 **근거 등급**: A 공시 세그먼트(Fiscal.ai `company_segments_and_kpis`·10-Q·분기보고서) / B 회사 IR 제품별 비중 / C 제3자 집계(TrendForce 보도자료) / E Chiip 브리지 추정(직전 C값 × 회사가 말한 비트·ASP 변화, 방법 필수) / U 미공시(합산 제외).
- 회계 분기는 달력 분기로 맞춘다(석 달 중 두 달이 든 분기).
- 회사 전체 지표(GPM·재고·CAPEX·컨센서스)는 '회사 전체' 표로만 보여 주고 산업 값에 섞지 않는다.
- A·B 근거가 풀 매출의 60% 미만이면 그 풀의 산업 판단 등급은 **보류**.
- 분기 관문(80% 발표)의 가중도 사업부 비중(share_hint)만큼만 센다.

## 3. 결정 B — IB 사고 논리 층(`config/industry_logic.yaml`, `scripts/industry/logic.py`)
형식만 가져온다(내용·도표·상품명은 쓰지 않는다).

| 장치 | 가져온 방법 | 관문 |
|---|---|---|
| 결론 먼저 + 인과 사슬 | 피라미드 원칙(Minto). 고리마다 증거 유형(확정사실~미확인), 가장 약한 고리 자동 표시 | 4고리 이상, 확정사실 1개 이상, 미확인이 있으면 '판단 가능' 금지 |
| 핵심 논쟁 | 월가 산업 노트의 Key Debates — 시장 견해(출처) ↔ Chiip 견해 ↔ 왜 다른가 ↔ 판가름 신호(날짜·지표·문턱) ↔ 확률 | 분기 3·주간 2·사건 2 |
| 가격 내포 기대 | Expectations Investing(Rappaport·Mauboussin) — 시장이 이미 가정한 숫자를 먼저 잰다 | 출처 필수. '간과·과소평가' 류 표현은 이것 없이 못 쓴다 |
| 동인 분해 | 매출 = 물량 × 가격 × 믹스(메모리 비트 × ASP 브리지). 코드가 실제 사업부 성장과의 잔차를 계산, 10%p 넘으면 경고 | 분기·주간 1개 이상 |
| 사이클 지표판 | 선행·동행·후행 구분(재고 vs 매출, 가격, 가동, CAPEX) | 분기 3개 이상 |
| 이익 풀 | Profit Pools(Gadiesh·Gilbert, HBR 1998) — 가치사슬 층별 마진 이동 | 분기·주간 필수 |
| 시나리오 | 약세·기본·강세, 확률 합 1, 확률 가중값 자동 | 세 개, 합 1 |
| 기저율 | 외부 관점(Mauboussin) | 선택 |

- 금지 표현(매매·비중 지시, '확실하다')은 관문이 막는다.
- 적용: 2026-11-09 이후 리포트(사건 심층 포함), 이전 발행분은 다시 만들 때.

## 4. 분기 결산 절 순서(개정)
결론(한 문장 + 인과 사슬) → ① 핵심 논쟁 → ② 시즌 스코어카드(사업부 기준 + 회사 전체 따로) → ③ 동인 분해 → ④ 무엇이 바뀌었나 → ⑤ 사이클 지표판 → ⑥ 이익 풀 → ⑦ 가격 내포 기대 vs Chiip(등급) → ⑧ 시나리오 → ⑨ 지난 판단 채점 → ⑩ 반대 검증 → ⑪ 체크포인트·반증 → 종료 상태.

## 5. 첫 적용 — 2026년 3분기 NAND·스토리지 시험판 2차
- NAND 4사 사업부 합계 $58.8B, 전분기 +32%(2분기 상위 5사 +77%에서 감속). HDD $8.6B, +17%(출하 용량 +0.9%, EB당 매출 +16%).
- 삼성전자 NAND 미공시 → 합산 제외(U). SK하이닉스는 E 브리지, 키옥시아는 C. NAND 공시·IR 근거 43% → 등급 보류, HDD In-Line.

## 6. 한계
- 풀은 NAND·HDD·D램만 정의했다. 다른 산업은 회사별 세그먼트 매핑을 풀로 추가해야 같은 방식이 된다(그 전까지는 GICS 묶음 + 회사 전체 매출).
- 삼성전자 메모리 제품별 매출은 회사가 공시하지 않아 제3자 집계 의존이 남는다.
- 매년 바뀌는 세그먼트 재분류(예: Micron 사업부 개편)는 지표명으로 매핑하므로 개편 때 설정을 고쳐야 한다.
