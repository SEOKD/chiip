# ADR-045 — 국장 주도주 생애 단계(생·로·병·사)(2026-11-15)

마스터 지시(2026-11-15): "국장 종목 분석 시 위 리포트의 메커니즘을 반영하도록 해라." (DB금융투자 강현기, 「주도주의 생로병사」 2018-10-17)

## 결정
- 리포트의 주도주 메커니즘을 결정론 판정 `scripts/discovery/kr_leader.py`로 옮긴다. 판정 순서는 장세(KOSPI 10/40주선) → 생(장세 첫 3개월 KOSPI 200 상위 5%) → 로(장세 나이별 순위 한계 36.8·23.5·19.8·16.4% 안 + 고점 대비 −30% 안 + 돌파 거래량) → 병(10주선 < 40주선) → 사(−30% 초과)다. 보조 지표는 상승·하락 속도 비, 직전 장세 강세, 매출·영업이익 TTM 증가다.
- 국장 종목 분석에 반영하는 경로
  - 데이터 허브: `config/analysis_sources.yaml` 원천 `kr_leader`(region kr)를 둔다. 데이터 허브를 읽는 모든 기능이 본다.
  - Analysis: 매수 위치·셀온 조건·체크리스트(`docs/channels/tenbagger.md`).
  - Portfolio: 보유 종목 단계 한 줄, 단계가 바뀐 날만 알림(`docs/channels/portfolio.md`).
  - Discovery: 장세 시작 3개월 안 상위 5% → 단서 장부, 국장 테마 대장주 확인(`docs/channels/discovery.md`, `sector_lenses/kr_theme.md`).
  - 토요일 스냅숏: `docs/tasks/chiip-tenbagger.md` 1-2 e-2.
- 상수 12개를 등록부 `prm-krld-*`에 사전값으로 등록했다(출처 = 이 리포트). 원문은 라이선스 자료라 `D:\local-only\licensed\db\`에 두고 저장소에는 메커니즘 요약만 둔다(`knowledge/methods/kr_leader_lifecycle.md`).

## 반대 검증으로 바꾼 것
- 리포트의 "−30%를 넘으면 95.3% 확률로 주도주가 아니다"는 역확률이다. '주도주의 95%가 −30% 안에서 멈췄다'에서는 그 결론이 나오지 않는다. 기저율(주도주 5%)이 빠졌기 때문이다. 그래서 필요조건 필터로만 쓰고 확률로 인용하지 않는다. 테스트가 이를 잰다.
- 장세 시작을 실시간으로 잡으려고 KOSPI 10/40주선 교차를 대리 규칙으로 썼다. 리포트는 사후 장기 사이클로 장세를 나눴으므로 이 대리 규칙은 검증되지 않았다고 표시했다.
- 직전 주도주 제외에는 그때의 KOSPI 200 순위가 필요하다. 그 스냅숏이 없어 지금은 종목 대 KOSPI 수익률만 보인다. 주 1회 스냅숏을 쌓기 시작했다.
- 생애 단계는 가격 판정이다. 구매 등급·펀더멘털 판단을 바꾸지 않고, 매수·매도 지시로 쓰지 않는다.

## 첫 판정(2026-11-15)
KOSPI는 2025-05-19~2026-10-12 상승 장세 뒤 10주선이 40주선 아래로 내려갔다. 판정을 돌린 SK하이닉스(−46%)·삼성전자(−47%)·두산(−69%)·ISC(−39%)는 모두 고점 대비 −30%를 넘어 '사(지위 상실 가정)'로 나왔다. 단 SK하이닉스는 회사 폴더 일봉이 11/2까지라 주봉을 새로 받아야 한다. 대한전선은 시세 파일이 없어 판정하지 못했다.

## 남긴 것
- 종목 변동성에 비례하는 조정 한계(고정 −30% 대신) — 표본 외 비교 뒤에만 채택.
- 국장 테마 엔진(`kr_theme.py`) 점수에 생애 단계를 직접 넣는 일 — 지금은 렌즈 문서로 확인만 한다.
