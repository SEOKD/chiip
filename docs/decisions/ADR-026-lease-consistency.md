# ADR-026 밸류에이션 엔진 리스 일관 처리 — 방식 A(리스 자본화)

- 날짜: 2026-11-13
- 마스터 지시: "고쳐라" — LTH 재발행(ffa93a4) 뒤 ROIC 약 6% < WACC, 어닝콜 '회비 +12%'가 주주가치 −2.1%, 몬테카를로 전부 −98%~−39%(목표주가 $41과 모순)
- 상태: **구현(2026-11-13)** — `scripts/valuation/v2/leases.py`, `run.load_company`, `scenarios.drivers`, 테스트 `tests/test_leases.py`

## 1. 진단 — 리스를 두 번 뺐다
| 자리 | 그전 | 문제 |
|---|---|---|
| 영업 마진(EBIT) | GAAP — 임차료 전액 차감 후 | 리스 이자 몫까지 영업비용 |
| 투하자본(ic0)·재투자 효율(s2c) | 자기자본 + 차입 + **리스** − 현금 | 리스 사용권자산을 자본으로 셈 |
| 순차입 | 규칙은 '리스 포함'(80개 datapack 대부분). LTH만 리스 제외 | LTH는 부채비중·WACC도 어긋남 |
임차료를 비용으로 빼고 그 자산도 자본으로 세면 NOPAT은 작고 자본은 커서 ROIC가 눌린다. ROIC < WACC면 성장할수록 가치가 줄어든다(LTH 회비 단가 −2.1%).

## 2. 결정 — 방식 A(리스 자본화)
`asset_roic_view`(커밋 0115398, ADR-021)의 NOPAT 정의와 같다 — Mauboussin·Callahan, "Return on Invested Capital"(Counterpoint Global 2022): NOPAT에 운영리스 비용 속 이자 몫을 되더하고, 투하자본에 리스 사용권자산을, 조달 쪽에 리스 부채를 둔다. B(리스 = 운영비)를 고르지 않은 이유: 80개 datapack이 이미 차입·투하자본에 리스를 넣고 있어 A가 고칠 곳이 마진 한 곳뿐이고, 리스가 큰 회사(헬스클럽·데이터센터·소매)의 자본 강도를 숨기지 않는다.
1. 리스 부채 L = datapack `leases.liab`, 없으면 최신 `raw.balance_*`의 lease_current + lease_lt. 0이면 아무것도 안 바꾼다.
2. 순차입: `profile.debt`에 L이 없으면 더한다(판정: 비리스 차입 칸 합과 비교, `leases.in_debt`로 지정 가능). WACC 부채비중에도 들어간다.
3. 마진: 모든 연도·시나리오에 L × r ÷ 기준 매출을 더한다(리스가 매출에 비례해 자란다고 가정). `scenarios.drivers` 한 곳이라 DCF·5년 뒤 가치·시나리오·몬테카를로·역DCF(필요 CAGR)·어닝콜 가치 영향·멀티플 대조가 모두 같은 정의를 쓴다.
4. r = 공시 운영리스 가중평균 할인율(`leases.rate`), 없으면 엔진 세전 차입금리(무위험 + 1.5%). 공시 r이 있으면 WACC의 세전 차입금리를 일반 차입·리스 잔액 가중으로 맞춘다 — 되더한 이자와 같은 금리로 할인.
5. 투하자본(ic0)·s2c는 그대로(이미 리스 포함). 카드에 '리스 자본화(방식 A)' 한 줄을 남긴다.
6. 끄기: datapack `"leases": false`. 비교용 `leases.ENABLED`.

## 3. 결과(2026-11-13, 기본 시나리오·같은 시드)
### LTH(리스 부채 $2.81B, 공시 할인율 9.28%)
| 지표 | 전 | 후 |
|---|---|---|
| WACC / 부채비중 | 8.96% / 10% | 9.12% / 27% |
| ROIC 1년차 → 5년차 | 6.4% → 6.4% | 9.3% → 9.5% |
| 회비 단가(growth_start +0.5%p) 가치 영향 | −2.07% | +0.87% |
| 기본 내재가치 / 시총 | 0.20배($9.11) | 0.38배($17.50) |
| 몬테카를로 지금 가치 P10·P50·P90 | −98%·−76%·−58% | −86%·−66%·−41% |
리스 모순은 풀렸지만 내재가치는 여전히 리포트 목표주가 $41(규칙 계산, 멀티플 기반)보다 낮다. 남은 차이는 리스가 아니라 **재투자 효율 s2c 0.55**(매출 1달러에 자본 1.8달러, 영업권 $1.24B 포함 평균값)와 컨센서스 마진 경로에서 온다 — 최근 1년 증분 매출 ÷ 증분 투하자본은 약 0.6, 증분 ROIC는 20% 안팎(자산 구성과 ROIC 절 자료)이라 평균 s2c가 신규 클럽 수익성을 과소평가할 가능성. 별도 결정 사항.

## 4. 한계·다음
- 리스 이자를 매출 비례로 늘린다 — 매각 후 재임차(LTH)처럼 리스 비중이 바뀌는 회사는 과대·과소가 생긴다.
- SOTP 사업부 가치(`sotp.py`)는 사업부 마진에 가산하지 않는다(사업부 리스 배분 자료 없음).
- 공시 할인율이 없는 회사는 엔진 차입금리(약 6.4%)로 이자를 잡는다 — 실제 리스 금리가 높으면 가산이 작다. datapack `leases.rate`를 채우면 정확해진다.
