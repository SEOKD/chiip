# ADR-018 Chiip Industry Quarterly — 분기 결산 산업 리포트 설계

- 날짜: 2026-11-08
- 마스터 지시: "분기 결산 산업 리포트 만드는 코드를 체계적으로 설계하라"
- 상태: **승인·구현(2026-11-08)** — 마스터 결정: ① 산업마다 따로 ② 산업별 구성 매출 80% 발표 관문 ③ 아시아 가이던스·재고 빈칸은 국내 증권사 공개 요약으로 보완(원천 사이트는 robots.txt가 막아 언론 보도 제목 경로, C등급) ④ 2026년 3분기 시험판(NAND·스토리지) 발송. 아래 2절의 '한 시즌 한 편'은 ①로 바뀌었다 — 산업마다 관문을 넘는 날 한 편씩. 주간 산업(ADR 없음, `docs/tasks/chiip-industry-weekly.md`)·사건 심층(`event_frame`)과 같은 렌더러·등급 규칙을 쓴다.

## 1. 이 리포트가 답하는 질문
실적 시즌이 끝났을 때 IB 리서치 하우스가 내는 'Earnings season wrap'이다. 독자의 질문은 셋이다.
1. **무엇이 바뀌었나** — 산업별로 숫자(성장·마진·가이던스·재고·CAPEX)가 직전 분기와 시즌 전 기대 대비 어디로 움직였나
2. **누가 유리해졌나** — 가치사슬 안에서 부가가치·가격 결정력이 어느 층으로 옮겨 갔나
3. **Chiip 판단이 맞았나** — 지난 분기·주간·사건 리포트의 예측을 채점하고, 다음 분기 판단 등급을 다시 매긴다

## 2. 범위와 단위
- **한 시즌에 한 편**, 11개 산업(주간 산업과 같은 `config/industry_weekly.yaml` 산업·구성 종목)을 모두 덮는다.
  - 앞부분은 11개 산업 스코어카드, 본문은 변화가 큰 상위 3개 산업 심층.
  - 산업마다 따로 쓰면 한 시즌에 11편이 되어 독자가 읽지 않는다.
- 시즌 = 분기 말 다음 달 초 ~ 분기 말 + 55일(미국·유럽 중심, 일본·한국·대만은 같은 창 안에 들어온다).

## 3. 언제 쓰나 — 결정론 관문
| 단계 | 시점 | 하는 일 |
|---|---|---|
| ① 기대 얼리기 | 분기 말(3·6·9·12월 말) | 구성 종목의 다음 분기·다음 회계연도 컨센서스를 얼린다. 기존 `scripts/fiscal/estimates.py`(발표 전 추정 동결)를 산업 구성 전체로 넓힌다. **시즌 전 기대가 없으면 '서프라이즈'를 잴 수 없어 관문에서 멈춘다** |
| ② 진행률 추적 | 시즌 중 매일 | Pulse가 `radar/industry_quarter.py status()`를 부른다(13F와 같은 꽂기). 산업별 발표 완료 비율(매출 가중) |
| ③ 작성 개시 | 구성 매출의 80% 발표 또는 분기 말 + 55일 중 먼저 | Pulse 데이터의 `industry_quarter.due` → 1회용 예약(fireAt) 하나를 그날 06:00에 건다. 마스터 승인 후 자동 |
| ④ 발송 | 작성 다음 날 07:56 | 주간 산업과 같은 send 방식 |

## 4. 데이터 — 종목별 분기 장부
`knowledge/models/industries/quarterly/<YYYYQn>/members.csv` — 종목 × 지표 1행. 수집은 결정론 스크립트가 요청 목록을 만들고, MCP 호출은 모델이 13F 방식(`--plan` → execute_code → `--put`)으로 한다.

| 지표 | 원천(1순위 → 2순위) |
|---|---|
| 매출·영업이익·GPM 실적, 전년·전분기 대비 | Fiscal.ai `quarters.js` → TradingView 분기 재무(일본·대만·한국) |
| 시즌 전 컨센서스 대비 서프라이즈 | ①에서 얼린 추정 → Fiscal `surprise.js` |
| 다음 분기 가이던스 vs 시즌 전 컨센서스 | 실적 보도자료·IR PT(`fiscal_ir_docs`·`jp_ir_docs`·`kr_ir_docs`·`tw_hk_ir`), 없으면 '미공시' |
| 다음 회계연도 추정 리비전(시즌 전 → 후) | 얼린 추정 vs 시즌 뒤 `company_estimates` |
| 재고일수·CAPEX·수주잔고 | 분기 재무(Fiscal 표준화), 수주잔고는 공시 문구 |
| 경영진 톤·질문 주제 | 어닝콜 전문 Q&A(`transcript_qa.js`) — 낙관·신중·가격·수요·공급 키워드 수 |
| 실적일 주가 반응 | 발표일 ±1일 초과수익(벤치마크 대비), TradingView OHLCV |

- 단위·회계연도가 다른 종목(3월 결산 일본, 52주 결산)은 분기 라벨을 달력 분기에 맞춘다(`sync_view.qlabel` 재사용).
- 맞출 수 없으면 '비교 불가'로 둔다.

## 5. 산업 집계 — 지표와 판정
산업마다 다음을 매출 가중으로 낸다(`scripts/industry/quarter_frame.py`).
- **성장·마진**: 매출 성장(전년), GPM 변화(%p)
- **서프라이즈 폭과 상회 비율**: 매출·EPS가 컨센서스를 넘은 종목 비중
- **가이던스 상향 비율**: 다음 분기 가이던스가 시즌 전 컨센서스보다 높은 종목 비중
- **리비전 폭(breadth)**: 다음 회계연도 추정을 올린 종목 수 − 내린 종목 수, 구성 종목 수로 나눈 값
- **재고·CAPEX 사이클**: 재고일수 변화, CAPEX/매출 변화
- **가격 반응과 일치도**: 서프라이즈 방향과 주가 반응의 부호 일치율 — 좋은 실적에도 빠졌다면 '기대가 더 높았다'의 정황
- **가치사슬 이동**: 같은 산업 안 층(장비·소재·부품·완제품·고객)별 GPM 변화 차이 — 부가가치가 어느 층으로 갔나

변화 점수 = 위 지표의 직전 분기 대비 z값 합. 상위 3개 산업을 본문 심층으로 고른다.
모델은 한 단계까지만 바꿀 수 있고, 바꾸면 이유를 남긴다.

## 6. 등급과 채점
- **산업 판단 등급**: 사건 심층·주간과 같은 규칙(`event_frame.rate` — 갭 ±5%p, 확신도 0.5, 토론 조정 한 단계).
  - 갭 = Chiip 다음 4분기 산업 성장 기대 − 시장 반영(시즌 뒤 컨센서스 성장 또는 가격 내포 성장).
- **채점**(`scripts/industry/quarter_score.py`): 예측 장부(`predictions.csv`)에서 기한이 이번 시즌 안에 든 IND·INW·INQ 예측을 판정하고 브라이어 점수를 낸다.
  - 지난 분기 등급(Attractive·Cautious)의 사업군 바스켓 초과수익도 계산해 '등급이 돈이 됐나'를 보인다.
  - 성적표(월 1회 점검)에 합친다.
- 다음 분기 체크포인트는 INQ로 등록한다. 사후 수정은 금지하고, 정정은 새 행으로 쓴다.

## 7. 리포트 구성(IB earnings wrap 양식, `industry_html` 렌더)
| 절 | 내용 |
|---|---|
| 결론 | 이번 시즌 한 문장 + 등급이 바뀐 산업 |
| ① 시즌 스코어카드 | 11개 산업 표(성장·GPM 변화·상회 비율·가이던스 상향 비율·리비전 폭·주가 반응·등급 직전→지금) + 히트맵 |
| ② 변화가 큰 산업 3곳 | 산업마다 무엇이 바뀌었나 → 왜(경영진 발언·수급·가격) → 누가 유리해졌나 |
| ③ 가치사슬 이동 | 층별 GPM 변화 그림, 부가가치가 어느 층으로 갔나 |
| ④ 재고·캐파·CAPEX 사이클 | 산업별 사이클 위치(P·Q 분해 재사용 — `pq_view` 산업 집계판) |
| ⑤ 지난 판단 채점 | 맞음·틀림·판정 대기, 브라이어 점수, 등급 바스켓 성과 |
| ⑥ 시장 반영 vs Chiip | 산업 등급표(규칙 계산) |
| ⑦ 반대 검증 | 이번 시즌 결론을 깨는 대안 설명(기저 효과·환율·일회성·재고 축적) |
| ⑧ 다음 분기 체크포인트 | 날짜·무엇·확률(INQ 등록) |
| 종료 상태 | 판단 가능 / 조건부 판단 / 핵심 근거 부족 |

텔레그램은 `tg_feed`(cycle `quarterly` = '분기 결산')가 같은 양식으로 만든다 — 스코어카드 상위 3줄 + 등급 변화 + 체크포인트.

## 9. 관문(멈추는 조건) — 빈칸을 채우지 않는다
- 시즌 전 기대 동결이 없는 산업 → 서프라이즈·리비전 칸은 '비교 불가'. 3개 산업 이상이면 리포트를 멈춘다.
- 구성 매출의 60% 미만이 발표한 산업 → 스코어카드에 '진행 중'으로만 넣고 등급을 매기지 않는다.
- 심층 3개 산업은 지표마다 출처가 있어야 한다. 경영진 발언은 전문이 있을 때만 쓴다(라이선스 자료라 요지와 15단어 이하 인용).

## 10. 마스터에게 정할 것
1. 한 시즌 한 편(11개 산업 스코어카드 + 심층 3)으로 할지, 산업마다 따로 쓸지 — 설계안은 한 편이다.
2. 작성 시점: 구성 매출 80% 발표(설계안) vs 고정 날짜(2·5·8·11월 25일).
3. 아시아 종목 가이던스·재고는 IR PT와 TradingView에 의존한다. 빈칸이 생기는 산업(수동소자·기판)을 '비교 불가'로 둘지, 국내 증권사 공개 요약으로 보완할지 — 후자는 라이선스 경계 확인이 필요하다.
4. 첫 시즌: 지금은 2026년 3분기 시즌 막바지다. 기대 동결이 일부 종목에만 있어, 첫 리포트는 2026년 4분기 시즌(2027년 2월)부터가 깨끗하다. 이번 시즌을 시험판으로 쓸지 정해 주십시오.
