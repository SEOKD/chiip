# 방법론 문서 자리

마스터가 아래 두 파일을 이 폴더에 넣어 주세요(파일 이름 그대로).

| 파일 | 내용 |
|---|---|
| `research_method.md` | 반도체·테크 산업 리서치 방법론 |
| `investment_style.md` | 주식 리서치 스타일 |

넣은 뒤 치입에게 "방법론 문서 넣었어"라고 하면:
1. 두 문서에서 규칙 후보를 뽑아 **"제안"** 으로 표시합니다(다른 AI가 과거 대화를 보고 추론한 문서라 그대로 확정하지 않음).
2. 문서끼리, 또는 지시서와 충돌하는 부분을 목록으로 보고합니다.
3. 과거 오류 사례를 `evals/cases/` 회귀 사례로 보강합니다.
