## 인과 사슬
1. 보도: 협상 근접 — **미확인**(익명 취재원, 1차 출처 없음).
2. 전략: MRVL은 광 모듈의 '두뇌'(PAM4·코히어런트 DSP, TIA·드라이버, 실리콘 포토닉스, CPO)를, LITE는 '광원'(InP EML·CW 레이저, 광 회로 스위치(OCS), 모듈)을 가진다 → 합치면 DSP+레이저+모듈+OCS 풀스택. 브로드컴(자체 EML·DSP·CPO 보유)과 같은 수직 통합 구도 — **확정(사업 구성)**, 효과는 **미확인**.
3. 병목: 1.6T 트랜시버·CPO의 레이저(InP EML·고출력 CW) 공급이 업계 병목으로 거론됨 → 레이저 내재화의 가치 — **자체추론**, 금지표 '부품 성능 개선 → 시스템 성능 개선' 주의(실제 병목·점유율 확인 필요).
4. 가치: 주식 교환이면 프리미엄 34% 이하에서 EPS 중립~증가 — **조건부**(선행 EPS 정의·조건 미확인).
