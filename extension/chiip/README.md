# 치입 크롬 확장 (Chiip for Chrome)

크롬 툴바의 치입 아이콘 → 옆 패널에서 **시장 체제·실적 일정(알파 5.0 이상 표시)·알파 잠재력 상위·포커스 점수 상위·최근 텔레그램 알림**을 보고,
보고 있는 기사·공시 페이지를 **치입에게 보내기**(레이더 판정) 또는 **⭐ 노션 기록**으로 넘긴다.
데이터는 마스터 PC의 치입 로컬 서버(`scripts/chiip_server.py`, 127.0.0.1:8765)에서만 온다. 모델(API)을 부르지 않아 비용이 없다.

## 설치 (처음 한 번)
1. **치입 서버 켜기**: PowerShell에서 `scripts/start_chiip_server.ps1` 실행(창을 닫으면 서버도 멈춤).
   - 처음 실행하면 `radar/state/ext_token.txt`에 토큰(비밀번호 같은 문자열)이 생긴다.
   - 로그인할 때 자동으로 켜려면(선택): `Win+R` → `shell:startup` → 열린 폴더에 `start_chiip_server.ps1`의 바로가기를 넣는다.
2. **확장 설치**: 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → `C:\Users\석진\chiip\extension\chiip` 폴더 선택. (크롬 116 이상)
3. **토큰 넣기**: 확장 카드의 **세부정보 → 확장 프로그램 옵션**(또는 옆 패널 아래 '설정') → `ext_token.txt`의 값을 붙여 넣고 **저장** → **연결 시험**에서 "연결됨"이 나오면 끝.
   - 툴바에 아이콘이 안 보이면 퍼즐 모양 아이콘 → 치입 옆 핀 고정.

## 쓰는 법
- **툴바 치입 아이콘** → 옆 패널이 열린다. 5분마다 자동 갱신, ↻로 즉시 갱신.
- **지금 보는 페이지 보내기**(옆 패널 위쪽): 메모 한 줄(선택) → **레이더 판정**(다음 수집 주기에 판정, 중요하면 텔레그램) 또는 **⭐ 노션 기록**(인텔 아카이브 대기열).
  페이지에서 문단을 드래그해 두고 보내면 선택한 문단도 함께 간다.
- **우클릭 메뉴**: 페이지·선택 영역·링크 위에서 '치입에게 보내기 (레이더 판정)' / '치입: ⭐ 노션 기록' / '치입 패널 열기'. 결과는 아이콘 배지(✓ 또는 !)로 잠깐 표시된다.

## 경계
- 서버는 이 PC 안(127.0.0.1)에서만 열리고, 요청마다 토큰을 확인한다. 일반 웹사이트는 서버를 부를 수 없다(CORS는 크롬 확장 출처에만 허용).
- 토큰·`ext_token.txt`를 채팅·저장소·다른 사람에게 공유하지 않는다(파일은 git 제외 폴더 `radar/state/`에 있다).
- 보낸 페이지는 '마스터 제보'(doc_type)로 레이더에 들어가 9개 매체·포커스 종목 수집 관문을 거치지 않는다 — 마스터가 직접 고른 페이지이기 때문. 판정·알림 규칙(P0~P3, 신선도)은 그대로 적용된다.
- 필드 인텔·엠바고·취재원 정보가 담긴 페이지는 보내지 않는다(레이더·노션 모두 공개 자료 경로).
- 확장은 크롬 웹 스토어에 올리지 않는다(개인 전용, 개발자 모드 로드).
